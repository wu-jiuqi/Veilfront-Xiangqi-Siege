《雾疆：九路烽棋》三关试玩版

运行：双击 Veilfront_Xiangqi_Siege_Level_Test.exe

目标：50个完整回合内消灭全部敌方棋子。
第一关：1枚敌方象；第二关：2枚敌方象；第三关：2枚敌方马。
开局：五个兵位于我方城墙线，其余棋子位于大本营。

操作：
- 左键选择棋子和目标点。
- Esc或选中棋子时右键取消。
- 未选中棋子时右键添加标注。
- 使用棋盘滚动条查看大本营、缓冲区和战区。
- 顶部可切换关卡、修改随机种子和重开。
