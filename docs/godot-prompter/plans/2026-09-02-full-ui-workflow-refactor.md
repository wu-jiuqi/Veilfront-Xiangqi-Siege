## 目标

在不修改规则、`PlayerView`、公开事件、回放、联网协议和页面业务语义的前提下，把当前九类正式 UI 迁移到统一的“原生语义控件 + 独立视觉层 + 预置节点 + 可中断 Tween + 显式焦点 + reduced-motion”实现基线。

本次覆盖主菜单、关卡选择、局域网大厅、对局 HUD、教学、暂停/设置、加载失败、终局结算和通用系统弹窗。兵马俑二维美术方向与当前公开信息边界保持不变。

## 新 Workflow 在本项目中的落地

- `Button` 只拥有输入、焦点、信号、文本和无障碍语义。
- 固定视觉结构全部预置在共享 `.tscn` 中，不由脚本动态拼装。
- 表面、阴影、插画、图标、文字、焦点框和状态标记是独立子层。
- 复杂插画使用保持比例的 `TextureRect`；九宫格只承载可安全拉伸的表面。
- 动效只改变 `offset_transform_*`、调制色和视觉层透明度，不改变布局矩形。
- 四种正式语义为 `Primary / Secondary / Danger / Confirm`；页面业务动作不因迁移而改变。
- 960×540、1280×720、1920×1080 与 2560×1080 共用 16:9 核心安全画布策略。

## 实施批次

1. 重构 `UiMotionButton` 共享预置、脚本与四种语义变体，补充结构合同测试。
2. 迁移主菜单、设置、关卡选择和局域网大厅的主要交互控件。
3. 迁移对局 HUD、教学、暂停、加载失败、结算和通用弹窗的主要交互控件。
4. 补齐全页面焦点闭环、无障碍名称、reduced-motion 和四档分辨率证据。

## 验收

- 共享按钮固定结构可在场景树中直接检查，根节点仍是原生 `Button`。
- 页面脚本继续使用原 NodePath、信号和动作语义，代表性流程合同全部通过。
- 所有正式主要动作都有非空语义角色、可见焦点和不低于 44 px 的交互高度。
- 鼠标 hover 不抢夺键盘/手柄焦点；禁用、聚焦、按下和 hover 的优先级一致。
- reduced-motion 下不发生位移、旋转、缩放、抖动或循环视觉运动。
- 四档分辨率无核心裁切、遮挡和焦点不可达；21:9 只扩展背景和安全留白。
- 自动检查通过后提交项目所有者体验验收；worktree 候选未获验收前不合入 `main`。

## 回退

每个批次独立提交。任一页面迁移造成布局、输入或视觉回归时，返回对应页面批次修复；共享组件合同失败时先返回第一批次，不在页面脚本中增加一次性补丁绕开共享约束。
