## 1. 推荐结论

推荐采用：**双入口、一套能力图谱、三层教学载体、两次实战验收**。

1. **双入口**：玩家选择“从基础学起”或“只学《雾疆》差异”，可随时换路线。
2. **一套能力图谱**：两条路线复用同一组正式规则局面，只改变顺序、默认提示强度和是否补基础走法。
3. **三层教学载体**：
   - 棋盘内互动训练：必须亲手完成的高频机制；
   - 战阵推演：修墙、后备、争旗、同窗结算等低频但重要的边界机制；
   - 战阵图鉴与首局情境提醒：用于复习，不代替互动验收。
4. **两次实战验收**：先通过“夺得第一面旗”的核心考核，再通过“攻守完整回合”的进阶考核。不能把看完说明或一路点箭头当作掌握。

推荐把“核心就绪”和“完整毕业”分开：玩家完成核心考核后即可自由进入其他模式；完整毕业仍要求覆盖下表所有已冻结机制。局域网入口不硬锁，只在关键能力未验证时显示一次非阻断提醒。

## 2. 教程范围与覆盖口径

### 2.1 FTUE 范围

本方案把 FTUE 定义为：从玩家第一次进入教学，到完成首次少提示夺旗，再到完成全部机制的进阶推演。它不是单一操作弹窗，也不是必须一次完成的 40 分钟长课。

### 2.2 覆盖状态

- `已覆盖`：现有 T0–T10 中已有行动或判断证据。
- `部分覆盖`：只讲到一部分、只写在总结/漫画中，或缺少玩家亲手验证。
- `缺失`：当前互动教程没有覆盖。
- `等待冻结`：正式规则尚未确定，教程只能显示动态配置或暂不教学具体值。

### 2.3 掌握证据

- **行动证据**：玩家在正式规则局面中完成动作。
- **预测证据**：玩家先判断结果，再观看正式结算。
- **辨析证据**：用于不能安全重复制造的低频终局或隐藏信息边界。
- 单纯阅读、观看动画或点击“下一步”不计为机制掌握。

## 4. 覆盖审计结论

现有 T0–T10 已经较好覆盖兵种特殊行动、迷雾、破墙、缓冲区前置、旗帜发现与首次占领，但**还不是全机制教程**。

必须补齐的 P0 缺口：

1. 七类棋子的完整普通行动；
2. 主棋盘浏览、小地图、镜像视角、行动/完整轮/跳过；
3. 非炮特殊行动的共同资格与敌墙倒塌后的失效；
4. 城墙修复、重新破坏、强制撤回与后备队列；
5. 旗帜占领中断、反占争夺与三旗胜利；
6. 炮击同步窗口、双将和局、将帅死亡结算优先级；
7. 一个真正允许至少两条合法解法的少提示综合考核。

当前无法完全冻结的内容：**完整轮上限具体数值**。它在正式规则中仍为 `unknown`。教程可以解释上限结算原则并读取公开战局配置，但不得写死“50 轮”等临时原型值。

## 5. 推荐课程结构

### 5.1 玩家可见路线

```text
首次进入教学
  → P0 雾中烽火（30 秒内第一次行动）
  → 选择路线
      ├─ 从基础学起：T0 → B1 → B2 → B3 → T1…T10
      └─ 只学《雾疆》差异：T0-S → T7/T4 自选顺序 → T1…T10
  → 核心考核：夺得第一面旗
  → 自由进入关卡/局域网（不硬锁）
  → 进阶推演：T8-R → T9-C → T10-E
  → 完整机制毕业
```

### 5.2 章节用途

| 模块 | 主要内容 | 路线 |
|---|---|---|
| P0 雾中烽火 | 第一次选择、预览、确认、揭雾与发现旗帜 | 两条路线 |
| T0 棋盘与军令 | 交点、镜像、浏览、小地图、标注、行动模式、回合与跳过 | 两条路线；熟练路线用压缩切片 |
| B1 直线先军 | 兵、车、炮普通行动 | 基础路线 |
| B2 跃阵双子 | 马、相普通行动、蹩腿与象眼 | 基础路线 |
| B3 九宫中军 | 士、将帅、九宫、本作基础胜负差异 | 基础路线 |
| T1–T7 | 七类棋子的《雾疆》特殊规则与实际阵亡 | 两条路线 |
| T8 雾墙攻防 | 完整墙、三子破墙、视野、缓冲区进营 | 两条路线 |
| T8-R 城墙余波 | 修复、中断、撤回、后备队列 | 完整毕业必做；核心考核后可续学 |
| T9 雾中旗帜 | 发现、记忆、占领和中断 | 两条路线 |
| T9-C 旗帜争夺 | 反占、contested、所有权保留与翻转 | 完整毕业必做 |
| T10 第一面战旗 | 少提示发现并夺得一面旗，至少两条合法解法 | 核心考核 |
| T10-E 终局推演 | 三旗、斩将、同步双将、结算优先级、轮上限原则 | 完整毕业考核 |

### 5.3 目标时长

| 里程碑 | 基础路线 | 象棋熟练路线 |
|---|---:|---:|
| 第一次有意义行动 | ≤30 秒 | ≤30 秒 |
| 核心就绪（通过 T10） | 25–35 分钟 | 12–18 分钟 |
| 完整机制毕业（含 R/C/E 推演） | 35–45 分钟 | 20–28 分钟 |

不要求一次完成。每个模块结束即保存公开检查点，重新进入时从章节边界恢复。

## 6. UX 展示方案

### 6.1 总体形式

教程采用**真实棋盘内的短军令 + 玩家行动 + 结果复盘**，不采用连续全屏 PPT，不建立与正式对局分叉的第二套操作界面。

每一步固定为四拍：

```text
当前军令（要做什么）
→ 玩家在正式棋盘上选择/预览/确认
→ 正式规则结算并给出可见结果
→ 一句话复盘（为什么会这样）
```

### 6.2 教学画面

复用正式 Match HUD，只增加预置教学抽屉；抽屉不遮挡棋盘核心交点。

```text
┌──────────────────────────────────────────────────────────┐
│ 章节 / 步骤 / 当前行动方 / 公开计时                      │
├──────────┬───────────────────────────────┬───────────────┤
│ 小地图   │                               │ 当前军令      │
│ 镜头框   │          正式主棋盘           │ 目标（常驻）  │
│          │      路径、相田、风险高亮      │ 原因（展开）  │
│ 单位卡   │                               │ 提示/重置     │
├──────────┴───────────────────────────────┴───────────────┤
│ 规则/技能简述       移动 | 技能       取消 | 确认行动     │
└──────────────────────────────────────────────────────────┘
```

规格：

- 1280×720 时教学抽屉宽 360–400 px；正文 16 px，辅助信息不低于 14 px。
- 目标始终可见，原因和图鉴按需展开；不能让玩家滚动后看不到“现在做什么”。
- 引导目标、合法落点、车路径、相田、炮击风险必须使用不同的颜色 + 线型/图标双重编码。
- 所有关键操作继续使用正式底部行动区和确认链。
- 支持鼠标、键盘/手柄焦点、960×540 紧凑布局和减少动态效果。

### 6.3 导师与情境

使用灰盒身份“军令使”作为克制的引导者，只负责：

1. 给出当前战场目标；
2. 在失败后解释公开原因；
3. 在完成后总结玩家掌握的能力。

开场用“前方烽讯已断，让斥候踏入迷雾找到第一面战旗”作为召唤。玩家在 30 秒内完成第一次行动，先看到揭雾结果，再学习术语。军令使不连续弹窗、不评价玩家聪明或棋力，也不在当前阶段冻结立绘、配音或剧情。

### 6.4 提示与失败恢复

| 触发 | 系统回应 |
|---|---|
| 初始 | 只给目标和相关机制，不画唯一答案；“显示提示/重置步骤”始终可用 |
| 第 1 次无效 | 显示正式公开拒绝原因，不消耗行动 |
| 第 2 次无效 | 高亮相关棋子、路径或机制区域 |
| 第 3 次无效 | 开放“查看演示”，只演示输入，不替玩家提交 |
| 第 4 次及以后 | 保留演示并开放“重置本步骤” |

错误次数只升级提示内容和目标揭示强度，不锁住提示或重置按钮。规则合法但偏离当前目标的行动可以预览；确认前提示“不会推进当前军令”。允许玩家观察后回到公开检查点，不能为了教程方便伪造该行动非法。

### 6.5 跳过、换路线与进度

能力状态至少区分：

- `UNSEEN`：未接触；
- `ASSUMED`：熟练路线中由玩家自报掌握；
- `COMPLETED`：有行动/预测证据；
- `SKIPPED`：明确跳过；
- `NEEDS_REVIEW`：综合考核暴露理解问题。

章节可跳过；跳过不伪装为完成。路线可随时切换并按能力合并进度。综合考核暴露的薄弱能力直接链接到对应完整模块。

### 6.6 战阵图鉴与首局情境提醒

现有 18 页四格漫画作为“战阵图鉴”使用：

- 只在章末复盘、暂停菜单和关卡目录中按需打开；
- 图片中的文字不能作为唯一信息源，标题和要点用可本地化文本层重做；
- 图鉴可以解释低频边界，但不能替代 T8-R、T9-C、T10-E 的互动证据；
- 玩家第一次在真实对局遇到破墙、争旗、献祭或后备部署时，可出现一次 1–2 行的非阻断提醒；同类提醒默认不重复。

## 7. FTUE 自检

### 7.1 英雄旅程

- **框架**：从进入教学到第一次独立夺旗是一段完整战场弧线，而不是操作清单。
- **召唤**：P0 先让玩家恢复烽讯、发现战旗，避免先读百科。
- **导师**：军令使只给目标、原因、结果，不成为文本框。
- **跨越门槛**：前两分钟内给予一次有意义选择；T10 至少允许两条合法解法。

### 7.2 心理需求

- **自主感**：可选路线、可换路线、合法偏离可观察、可跳过但状态诚实。
- **胜任感**：基础走法与特殊规则分层；提示逐级升级；失败只重置当前公开检查点。
- **关联感**：以接掌军队、恢复烽讯和争夺战旗形成最小情境，不用长剧情阻塞操作。

### 7.3 主要流失风险

| 风险 | 对策 |
|---|---|
| 零基础玩家同时学普通走法和特殊规则 | B1–B3 与 T1–T7 分层 |
| 象棋玩家被迫重复基础内容 | 差异路线跳过 B1–B3，优先展示破常规则 |
| 一路照箭头，进入对局后崩溃 | T10 至少两解，默认不显示唯一棋子/落点 |
| 全机制一次灌完导致退出 | 核心就绪与完整毕业分段，章节级保存 |
| 教程提示泄露隐藏信息 | 只消费 PlayerView / VisibleEvent / VisibleError / ActionPreview，做隐藏等价回归 |
| 教程脚本与正式规则漂移 | 所有玩家与脚本行动提交正式 Intent；重试重建权威 Scenario |

## 8. 验收标准

### 8.1 内容完整性

1. 上表所有非“等待冻结”条目都有唯一教学落点与掌握证据。
2. 每个关键机制至少有一个正向行动；高风险误解至少有一个拒绝、预测或辨析证据。
3. 跳过、阅读图鉴和观看演示不计为 `COMPLETED`。
4. T10 至少存在两条可完成的合法行动链，不能是猜唯一脚本。

### 8.2 体验指标

- 两类玩家首次有意义行动中位数 ≤30 秒。
- 至少 80% 测试者无需口头协助即可通过所选路线的核心考核。
- 至少 70% 测试者在最多一次重试内通过 T10。
- 差异路线结束后，不再把将军/飞将当作本作强制规则。
- 完整毕业后，玩家能用自己的话说明破墙修复、旗帜争夺和两种终局路径。

### 8.3 可用性与信息安全

- 960×540、1280×720、1920×1080 与 21:9 背景延展下无核心裁切。
- 核心正文 15–16 px 以上，关键按钮点击高度不低于 44 px。
- 鼠标、键盘/手柄焦点均可完成路线、提示、重置、跳过与返回。
- 隐藏等价 FullState 产生相同提示、高亮、错误和模块推进结果。

## 9. 需要项目所有者确认的决定

1. 是否采用“双入口、一套能力图谱”的总体结构；
2. 是否同意“核心就绪后可自由进入其他模式，完整毕业继续补全低频机制”；
3. 是否批准新增 P0、B1、B2、B3，以及 T8-R、T9-C、T10-E 进阶切片；
4. 是否接受基础路线完整毕业 35–45 分钟、熟练路线 20–28 分钟，并允许分多次完成；
5. 是否采用正式 Match HUD + 360–400 px 教学抽屉，而非全屏 PPT；
6. 是否采用能力状态 `UNSEEN/ASSUMED/COMPLETED/SKIPPED/NEEDS_REVIEW`；
7. 是否保留“军令使”作为灰盒引导身份，但暂不冻结立绘、配音与剧情；
8. 在完整轮上限仍未冻结前，是否同意教程只解释结算原则并读取战局配置。

## 10. 管线与实现边界

- 当前 GATE-3 v1 只批准补全现有 T0–T10；双轨 P0/B1/B2/B3 和新增进阶切片不在当前合同内自动获批。
- 若项目所有者批准本方案，应先形成 GATE-3 Contract 修订或独立批准附录，再进入 Godot 生产。
- 固定 UI、教学抽屉、路线选择、章节页、完成/失败页优先使用预置 `Control / Container / Theme / Resource`。
- 教学只消费正式观察者安全 DTO；不得读取 `FullState`、未发现旗位、隐身棋或规则 RNG。
- 当前 `step_effects / apply_tutorial_transition` 只能作为灰盒兼容债务，不得扩展为正式教程规则旁路。
- 本文件是审查提案，不替代 `veilfront-ftue-formal-level-design-v2.md` 或 `veilfront-ftue-dual-track-complete-design-v1.md`。批准后再合并并建立唯一生产事实源。
