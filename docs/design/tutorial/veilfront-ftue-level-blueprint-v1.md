# 新手教程关卡提案 v1：雾门初阵

## 一句话目标

用一个 12-18 分钟、五章节、可随时重试或退出的固定战局，让玩家在不读取隐藏状态、不绕过正式规则的前提下，独立完成一次夺旗。

## 关卡结构

| 章节 | 玩家要学会 | 固定局面与允许行动 | 失败、重置与完成 |
|---|---|---|---|
| 一、落子有据 | 棋子落在点线交点；左键选择与确认；右键取消/标注 | 红方车与兵位于己方缓冲区附近；只开放一次普通移动、一次取消和一次标注 | 点错不消耗回合；确认合法移动后 checkpoint |
| 二、雾中见旗 | 视野、黑色迷雾、旗帜首次发现与永久记忆 | 用兵或相走入预设视野；旗帜在进入 PlayerView 前完全隐藏 | 若走错给方向提示但不揭旗；发现旗后显示永久图标并 checkpoint |
| 三、破墙进营 | 墙未倒塌时不能进入敌墙线；墙破后仍须先进入缓冲区，下一步才能攻击大本营 | 固定敌墙、红炮/车与目标子；依次完成破墙、进缓冲区、攻营 | 试图从战区直击敌营返回公开错误，不消费行动；完成三步后 checkpoint |
| 四、线与田 | 车的蓝色路径；相的黄色田字九点；相田阻挡敌车和敌兵；隐藏马接触时车吃马并停点 | 一段车路径和一个相田重叠；先让玩家预测停止点，再提交真实 Intent | 错误预测只重置本章节；正确观察两次停止规则后 checkpoint |
| 五、夺旗与代价 | 占旗进度 1/3-3/3；士献祭需确认/可取消；士和将帅不进入复活随机池 | 已发现旗、一个可占旗子、一枚己方士与公开阵亡池 | 中断占领展示进度变化；取消献祭不消费；完成夺旗并做出一次献祭选择后进入终局 |

## 终局小考

- 棋子数量控制在每方 4-6 枚，敌方使用固定可见脚本，不使用 AI 搜索。
- 玩家目标是在 3-5 个己方行动内完成一面旗帜占领；不要求击杀将帅。
- 第一轮不显示直接箭头，只保留目标文案、合法高亮与已学过的视觉语义。
- 连续两次无效操作后提供一级提示；连续三次后提供可选演示，但演示仍提交合法 Intent。
- 完成后给出三项回顾：发现过的旗、曾进入的缓冲区、一次被规则截停的路径。

## 教学脚本合同

每章使用预置 `TutorialScenarioDefinition` Resource，至少冻结：

- 初始 authority state 或可验证状态引用；
- 绑定席位、固定 seed、允许的 `NormalizedIntent` 集合；
- 等待的 `VisibleEvent`/`VisibleError` 条件；
- 提示层级、checkpoint、失败和完成条件；
- 重试、跳过、退出权限；
- 只面向 PlayerView 的演示数据。

`TutorialDirector` 只消费安全 DTO 并请求 application 用例；不得读取 FullState、设置棋子位置、伪造 DomainEvent，或根据隐藏旗帜/隐身棋子改变提示。敌方固定脚本同样通过 application 提交合法 Intent。

## 表现与美术需求

- 继续使用 90° 俯视、点线棋盘与正方形点距。
- 区域只用颜色块和不越界的大号半透明区名，不使用分割线。
- 迷雾为黑色蒙版；可见敌子、旗帜和路径穿透蒙版；已发现旗只保留记忆图标。
- 蓝色仅用于车路径，黄色仅用于相田九点；普通落点、错误、标注与教程箭头使用不同明度/形状。
- 被吃位置保留一回合虚影；教程只解释第一次出现，不重复弹窗。

## 验收标准

1. 首次体验目标时长 12-18 分钟，任一章节可失败、重置、跳过或退出。
2. 三种目标分辨率下提示、棋盘和确认面板无裁切，点距保持正方形。
3. 所有玩家和敌方脚本行动都形成合法 Intent 与 DomainEvent；不存在直接状态写入。
4. 对隐藏旗、隐藏马、隐藏相田、RNG 与私有标记执行提示层 hidden-equivalence，公开输出必须相同。
5. 城墙/缓冲区/大本营、相田阻挡、旗帜记忆、占领进度、士献祭取消均有正负流程测试。
6. 5 名陌生测试者中至少 4 名无需口头指导完成终局小考；未通过时优先调整提示和局面，不改规则。

## 需要项目所有者确认的三点

1. 教程是否允许“可选演示”，还是失败三次后仍只给文字/箭头提示。
2. 士献祭章节是否要求玩家必须执行一次，或只要求打开、理解并可取消。
3. 终局小考采用红方固定身份，还是首次进入时允许选择红/黑并镜像局面。
