# 《雾疆：九路烽棋》双轨新手教学完整设计 v1

状态：`proposal / pending-project-owner-approval`

日期：2026-08-22

用途：定义“从未玩过象棋”与“玩过象棋”两条新手教学路线的完整体验、内容编排、共享模块、提示与失败策略、进度模型、Godot 资源映射和灰盒验收标准。

本提案不修改任何正式规则。项目所有者批准后，它将修订 `veilfront-ftue-formal-level-design-v2.md` 的目标玩家、章节路由和节奏部分；T1–T10 已批准的规则教学目标、固定局面意图和信息安全边界继续有效。

## 1. 执行结论

项目应提供两个明确入口，但只维护一套教学能力图谱：

1. **从基础学起**：面向从未玩过或不会基本走法的玩家，先建立本作实际采用的普通行动规则，再学习《雾疆》特殊行动与战场系统。
2. **只学《雾疆》差异**：面向会中国象棋基本走法的玩家，跳过基础模块，直接纠正传统经验迁移并进入迷雾、兵种特殊行动、城墙、旗帜与献祭教学。

两条路线共用同一个规则核心、权威 Scenario、PlayerView、可见事件和模块资源。路线只决定模块顺序、章节分组、默认提示强度和哪些基础能力被标记为“玩家自报已掌握”，不得复制规则实现。

推荐首通目标：

| 路线 | 目标时长 | 玩家最终应证明的能力 |
|---|---:|---|
| 从基础学起 | 25–35 分钟 | 理解交点、回合、移动、吃子、七类棋子普通行动，并能组合特殊行动完成一次夺旗 |
| 只学《雾疆》差异 | 12–18 分钟 | 不再套用错误的传统规则，能组合至少两种特色机制完成一次夺旗 |

## 2. 设计问题

现有 T0–T10 同时服务两类玩家，主要风险不是规则覆盖不足，而是学习顺序不适配：

- 零基础玩家会在第一次接触一枚棋子时，同时承受基础走法、特殊资格、迷雾反馈和例外规则，形成认知过载。
- 象棋玩家已掌握大量基础动作，如果必须完整重复七类棋子普通走法，容易产生无聊、跳读和过度自信。
- 象棋玩家最危险的失败来自“错误经验迁移”，例如默认存在将军/应将/飞将，默认兵卒需要过河，或把城墙倒塌视为可以直接从战区进入大本营。
- 如果为两类玩家复制两套局面、文案和测试，任何规则修订都会产生双倍维护和内容漂移。
- 如果教程只验证玩家能否服从箭头，玩家进入真人对局后仍可能无法自行判断。

## 3. FTUE 范围与体验承诺

### 3.1 范围

本设计覆盖：

- 玩家第一次进入教学后的前 30 秒；
- 路线选择；
- 第一轮本作普通行动学习；
- 第一轮特色兵种和系统学习；
- 第一次少提示综合夺旗；
- 章节重试、跳过、退出、恢复、换路线和复习；
- 灰盒试玩数据与验收。

不包含：

- 完整 AI 人机对战；
- 自由开局或残局题库；
- 最终角色立绘、配音或剧情演出冻结；
- 互联网账号、云进度或联网教学；
- 对正式规则的任何改写。

### 3.2 体验承诺

- 进入教学后 30 秒内完成第一次有意义的棋盘行动。
- 先让玩家看到行动产生的战场结果，再解释规则名称。
- 单次文字说明不超过两个短段；长规则拆到行动前、行动后和可展开百科。
- 非法点击和教学目标外尝试不羞辱玩家，不消耗正式行动机会。
- 两条路线最终都用一场少提示实战验证能力，而不是以阅读完成或选择题完成代替掌握。

## 4. 玩家分层与入口

### 4.1 分层定义

**从基础学起**适用于：

- 没玩过中国象棋；
- 认识少量棋子，但说不清基本走法；
- 希望按完整顺序学习；
- 不确定自己是否掌握基础。

**只学《雾疆》差异**适用于：

- 能说清车、马、相/象、士、将/帅、炮、兵/卒的基本走法；
- 了解传统吃子、蹩马腿、堵象眼、九宫和炮架；
- 不要求具有棋力、开局或残局经验。

“玩过象棋”不等于“高水平玩家”。该路线只跳过基础动作，不跳过任何《雾疆》改写规则。

### 4.2 首次入口界面

标题：**选择你的入阵方式**

说明：**两条路线可以随时切换，已经完成的内容不会丢失。**

按钮：

1. **从基础学起**
   辅助文案：没玩过或不熟悉象棋，从棋子走法开始。预计 25–35 分钟。
2. **只学《雾疆》差异**
   辅助文案：会基本走法，直接学习迷雾、特殊行动、城墙和战旗。预计 12–18 分钟。

规则：

- 默认键盘焦点放在“从基础学起”。
- 不使用强制知识考试或后台猜测玩家水平。
- 选择结果写入本地进度，但设置与教学目录始终提供“更换路线”。
- 更换路线按能力检查点合并进度，不清空另一条路线。
- 选择“只学差异”后仍可在棋子信息页点击“查看基础走法”。

## 5. 第一段英雄旅程

### 5.1 召唤：雾中烽火

玩家不是来填写规则表，而是接管一支在战争迷雾中失去战旗坐标的军队。第一条军令只有一句：

> 前方烽讯已断。让斥候踏入迷雾，找到第一面战旗。

玩家选择一枚红兵并移动。雾层退开，远处短暂出现旗帜记忆图标。该行动只教学“选择—预览—确认—结果”，暂不解释完整占领、城墙或特殊兵种。

### 5.2 导师：军令使（暂名）

导师只承担三个职责：

- 给出当前战场目标；
- 在失败后解释公开原因；
- 在章节完成后用一句话总结玩家刚刚掌握的能力。

导师不是连续弹窗，也不要求新增角色立绘。灰盒阶段使用姓名、短句和图章即可；最终是否具象化由后续叙事与美术评审决定。

推荐语气：克制、可信任、把玩家当作正在接掌军队的指挥者。避免“笨蛋式纠错”“连续夸奖”和百科式长篇讲解。

### 5.3 跨越门槛

两条路线的第一次自主判断都发生在前两分钟内：

- 基础路线：玩家在多个合法交点中选择一种普通移动完成侦察。
- 差异路线：玩家在“车路径穿杀”与“帅进入攻击范围”两个演示局面中选择先体验哪一个。

这一选择不改变正式规则结果，只改变两个短模块的播放顺序，用于建立自主感。

## 6. 共享能力图谱

所有章节最终映射到以下能力，而不是只记录“某一关被点完”。

| 能力 ID | 玩家应掌握的能力 | 最低通过证据 |
|---|---|---|
| C-INPUT-01 | 选择、取消、预览、确认和本地标注 | 完成一次取消、一次确认移动；标注不被当作行动 |
| C-BOARD-01 | 棋子位于交点，九路完整，红黑仅表现旋转 | 在目标交点完成移动，不点击格心误判 |
| C-TURN-01 | 双方轮流获得行动机会 | 完成一次己方行动并识别一次对方行动窗口 |
| C-PIECE-PAWN | 兵卒前/左/右一步、不可后退 | 完成两个不同方向的普通行动或判断 |
| C-PIECE-ROOK | 车直线移动、友军阻挡 | 完成一次普通移动并识别友军阻挡 |
| C-PIECE-CANNON | 炮普通移动与隔一架精确吃子 | 完成一次隔一架吃子 |
| C-PIECE-HORSE | 马走日且大本营内受蹩腿 | 完成一次合法日字并观察一次蹩腿拒绝 |
| C-PIECE-ELEPHANT | 相走田且大本营内受象眼 | 完成一次合法田字并观察一次象眼拒绝 |
| C-PIECE-ADVISOR | 士在九宫内斜走 | 完成一次九宫斜走 |
| C-PIECE-GENERAL | 将帅在九宫内直走 | 完成一次九宫移动 |
| C-FOG-01 | 普通 3×3 视野、移动后旧区回雾 | 用移动揭开新区域并观察旧区回雾 |
| C-SPECIAL-PAWN | 兵卒直线 2–5 点穿敌不伤、终点为空 | 完成一次穿越并正确判断沿途敌棋存活 |
| C-SPECIAL-HORSE | 特殊马无视马腿、落点隐身、需原因显形 | 完成越腿并观察相田显形 |
| C-SPECIAL-ELEPHANT | 特殊相无视象眼、提供扩展视野与田字阻挡 | 正确预测敌车和敌兵首次停止点 |
| C-SPECIAL-ROOK | 车路径顺序处理、路径视野、隐身马接触停点 | 完成一次多目标行动和一次隐藏接触 |
| C-SPECIAL-CANNON | 大本营炮击、完整 3×3、三点随机、允许友伤 | 完成一次固定种子轰炸并理解无共享冷却 |
| C-SPECIAL-ADVISOR | 士献祭、可取消、随机复活合资格阵亡棋 | 先取消再确认，并排除士与将帅候选 |
| C-GENERAL-DEATH | 没有将军/应将/照面/飞将，实际死亡才结算 | 将帅进入攻击范围后继续对局，再实际吃将 |
| C-WALL-01 | 三子破墙、修复、区域视野不等于反隐 | 触发一次破墙并正确判断隐身信息 |
| C-BUFFER-01 | 进入敌方大本营必须从缓冲区起步 | 先观察直接进营拒绝，再完成两段进攻 |
| C-FLAG-01 | 旗位受迷雾、发现后永久记忆 | 发现旗帜并观察离开视野后的记忆 |
| C-FLAG-02 | 占领绑定棋子并持续到 3/3 | 维持同一棋子完成占领 |
| C-VICTORY-01 | 三旗胜利、将帅死亡最高优先级 | 在总结或实战中正确识别两种胜负路径 |
| C-ASSESS-01 | 少提示组合侦察、路径判断、资源使用和占领 | 在行动限制内独立夺得目标旗 |

## 7. 共享教学模块

模块是最小权威局面。用户看到的是路线章节；一个路线章节可以串联多个模块。现有 T0–T10 保留为稳定模块 ID，新增 P0 与 B1–B3 四个基础模块。

同一模块可以预置多个**公开步骤切片**，格式为“起始步骤—完成步骤—提示档”。切片只能跳过已经声明为独立、无状态依赖的教学步骤；准备时必须验证后续行动在初始 Scenario 或前序已执行步骤下仍然合法。切片结束后按本路线记入对应能力，再用新的权威会话进入下一个模块，不能在运行时直接把棋盘改成某个中间状态。

### P0 雾中烽火：第一次有意义的行动（新增）

**适用路线**：两条路线。

**目标**：在 30 秒内完成选择、预览、确认，并看到迷雾退开和旗帜记忆。

**固定局面意图**：

- 红兵位于 `(5,10)`；目标 `(5,11)` 为空。
- 教学旗位于 `(6,12)`，初始不在红方 PlayerView 中。
- 移动后新视野覆盖旗位；只显示“已发现战旗”，不进入占领流程。
- 场景只使用正式预览、确认、行动和 PlayerView 更新。

**通过条件**：玩家确认一次移动并首次发现旗帜。

**差异路线附加钩子**：完成后允许选择先体验“车穿阵”或“帅入险地”。

### T0 棋落交点：操作校准（继承并重排）

**适用路线**：基础路线必做；差异路线可跳过。

**调整**：P0 已承担第一步移动，T0 聚焦右键取消、圆/叉/方标注、确认栏和交点误点反馈，不再充当情绪开场。

**通过条件**：一次取消、一次本地标注、一次确认行动；标注不改变合法落点。

### B1 直线先军：兵、车、炮普通行动（新增）

**适用路线**：基础路线。

**目标**：先理解本作普通行动，不同时引入特殊路径穿杀或轰炸。

**局面约束**：棋子位于己方大本营或不满足特殊资格的位置。

**玩家步骤**：

1. 兵向前一步，再在下一个子局面横向一步；尝试后退得到公开拒绝。
2. 车沿直线移动；用友军展示不能穿越。
3. 炮普通移动，再隔恰好一枚炮架吃子。

**通过条件**：三类棋子各完成一次普通行动，并能区分“炮移动不需要炮架，炮吃子需要一架”。

### B2 跃阵双子：马、相普通行动（新增）

**适用路线**：基础路线。

**玩家步骤**：

1. 马完成一次合法日字移动。
2. 在己方大本营观察一次蹩马腿拒绝。
3. 相完成一次合法田字移动。
4. 在己方大本营观察一次堵象眼拒绝。

**通过条件**：玩家能从高亮形状预测马和相的终点，并识别马腿与象眼不是终点本身。

### B3 九宫中军：士、将帅与基础胜负（新增）

**适用路线**：基础路线。

**玩家步骤**：

1. 士在九宫内斜走一步。
2. 帅在九宫内直走一步。
3. 尝试离开九宫并获得公开拒绝。
4. 只说明“本作有夺三旗和实际吃掉将帅两条核心胜利路径”，细节延后。

**通过条件**：完成两类九宫移动并识别九宫边界。

### T1 穿阵不伤：兵卒特殊行动（继承）

- 保留 `(5,10)→(5,11)→(5,15)`、穿过黑卒和黑炮、友军负例。
- 基础路线在进入模块前已完成 C-PIECE-PAWN；差异路线先用一句对比文案指出“本作兵卒始终按过河后的方向能力处理”。
- 通过证据：完成 2–5 点特殊穿越并确认沿途敌棋不受伤、不形成路径视野。

### T2 越腿入雾：马特殊行动（继承）

- 保留大本营蹩腿拒绝、特殊区域越腿、隐身和相田显形。
- 差异路线不重复解释日字几何，只强调本作的资格覆盖与隐身。
- 通过证据：完成特殊移动，并正确判断城墙倒塌区域视野不自动反隐。

### T3 田字封路：相象特殊行动（继承）

- 保留无视象眼、起点/田字/终点视野并集、敌车与敌兵首次进入截停。
- 黄色只描田字九点，不能把全部视野画成阻挡区。
- 通过证据：正确预测 `(5,11)` 与 `(4,12)` 两个停止点。

### T4 蓝线开路：车特殊行动（继承）

- 保留多目标顺序处理、完整路径视野、隐身马接触停点和己方阵亡虚影。
- 蓝色路径只表示本次车行动，不表示永久控制区。
- 通过证据：完成多目标行动，并正确解释隐身马接触结果。

### T5 一架一轰：炮与区域轰炸（继承）

- 保留普通炮隔一架吃子和另一门炮从己方大本营轰炸。
- 预览只显示中心、风险区、弹药和友伤可能，不预告三个随机命中点。
- 通过证据：完成两种行动并确认没有阵营共享冷却。

### T6 以身换援：士献祭（继承）

- 保留九宫斜走、先取消、主动继续、再确认献祭的完整顺序。
- 取消后必须停留在“士仍在场、行动未消耗”的稳定状态。
- 通过证据：指出公开阵亡记录不等于复活候选池，士与将帅被排除。

### T7 实际阵亡：将帅规则重置（继承）

- 保留帅进入敌方攻击范围仍继续对局，以及红车实际吃掉黑将。
- 差异路线可将本模块提前为第一组“破常识”内容。
- 通过证据：玩家能明确回答“进入攻击范围不会失败，实际被吃才失败”。

### T8 雾墙攻防：城墙与缓冲区（继承）

- 保留第三枚入侵者进入缓冲区破墙、倒塌区域视野、直接进营拒绝和两段进攻。
- 补充一个非提交观察：墙进入 `REPAIRING` 后双方各行动一次才恢复，入侵数回到三枚会重新倒塌。
- 通过证据：完成破墙与战区→缓冲区→大本营顺序，并区分区域视野与反隐。

### T9 雾中旗帜：发现与占领（继承）

- 保留相扩展视野发现旗帜、离开后记忆、红兵占领到 3/3。
- 公开占领消息不得向未发现方附带旗坐标。
- 通过证据：玩家能解释占领进度绑定具体棋子，离开、死亡或献祭会清零。

### T10 第一面战旗：综合考核（继承并分提示档）

共同硬目标：

1. 建立视野并发现目标旗；
2. 正确处理一次隐藏路径接触或相田阻挡；
3. 让指定或自主选择的合适棋子抵达旗点；
4. 在八个己方行动内完成 3/3 占领。

基础路线默认提示：显示目标区域，不显示唯一行动；两次失败后显示相关机制高亮。

差异路线默认提示：只显示文字目标；两次失败后才显示目标区域，三次失败后提供演示。

结算回顾统一显示：侦察、路径判断、资源使用、无效操作。不得以分数评价玩家聪明程度或象棋水平。

## 8. 路线 A：从基础学起

路线 ID：`foundation`

### A0 雾中烽火（约 1 分钟）

模块：P0。

玩家感受目标：**我已经开始指挥，而不是还在读说明。**

完成后显示一句总结：**视野跟着棋子前进；战旗需要先被发现。**

### A1 棋盘与军令（1–2 分钟）

模块：T0。

内容：交点、选择、取消、标注、预览、确认、回合窗口。

章节结束后开放棋子信息抽屉和随时查看的“基础走法”页。

### A2 七子初阵（5–7 分钟）

模块：B1、B2、B3。

章节内部按三个小场景切换，每个场景完成后立即总结，不在开始前一次展示七枚棋子的所有说明。

通过条件：七类棋子的普通行动能力全部达到 `COMPLETED`。

### A3 雾战异法（5–6 分钟）

模块：T1、T2、T3、T4。

编排理由：先从移动变化较直观的兵开始，再进入隐身、显形、阻挡和路径接触，逐步增加隐藏信息复杂度。

章节结束选择题只保留两道预测题：相田停止点和隐身马接触点。其余规则通过行动结果验证。

### A4 火与援军（3–4 分钟）

模块：T5、T6、T7。

内容：炮击风险、献祭取消与确认、将帅实际死亡。

情绪目标：让玩家感到自己正在做资源和牺牲决策，而不是只学习棋子走法。

### A5 破墙入营（2–3 分钟）

模块：T8。

通过条件：完成三子破墙和两段进营，并观察一次修复说明。

### A6 雾中旗帜（2–3 分钟）

模块：T9。

通过条件：发现、记忆并完成一面旗的占领。

### A7 第一面战旗（5–7 分钟）

模块：T10。

完成后开放：

- 关卡目录中的挑战关；
- “只学差异”路线的模块复习入口；
- 局域网对战入口提示，但不强制立即进入联机。

## 9. 路线 B：只学《雾疆》差异

路线 ID：`xiangqi_experienced`

选择路线时，将 C-PIECE-* 基础能力记为 `ASSUMED`，不记为 `COMPLETED`。玩家切换到基础路线时仍可正式完成。

### X0 破常一手（约 1 分钟）

模块：P0，然后由玩家选择先进入 T4 的车穿阵演示或 T7 的帅入险地演示。

玩家感受目标：**这不是加了迷雾的普通象棋。**

玩家在 X0 完成的钩子切片会写入能力记录，后续章节不会强制重复同一切片。

### X1 旧法新规（约 2 分钟）

模块：T7、T1，并插入一张可操作对比卡说明：

- 无将军、应将、将死、照面和飞将；
- 将帅实际死亡才结算；
- 兵卒始终可以前、左、右一步；
- 马、相可跨全盘行动，但普通限制与特殊资格仍按区域和城墙状态区分。

对比卡只在每项对应行动发生后出现，不在开场连续展示。

### X2 雾战兵法（3–4 分钟）

模块：T2、T3、T4。

核心链路：隐身马进入战区 → 相田使其显形 → 敌车/敌兵被相田截停 → 车路径接触另一个隐身马。

章节通过条件：至少一次由玩家自己预测，而不是完全观看脚本。

### X3 攻城、炮火与援军（3–4 分钟）

模块：T5、T6、T8。

核心链路：炮击制造风险 → 士献祭回收资源 → 三子破墙 → 遵守缓冲区前置进入敌营。

默认不重复炮普通移动、士普通斜走等基础说明；信息抽屉仍可展开。

### X4 第一面战旗（4–6 分钟）

模块：T9 的发现与记忆前半段，随后进入 T10 综合考核。

T9 的完整 3/3 演示不强制重复；玩家在 T10 中亲自完成占领即可同时取得 C-FLAG-02。

完成条件：在八个己方行动内夺旗；允许使用三级提示，但结算记录是否使用。

### 9.1 差异路线模块切片

差异路线用以下切片压缩重复内容，所有被保留的行动仍经过同一正式规则：

| 模块 | 差异路线必做步骤 | 跳过内容 |
|---|---|---|
| T1 | 特殊穿越、结果确认 | 普通一步演示 |
| T2 | 越腿隐身、相田显形、反隐判断 | 基础日字说明 |
| T3 | 特殊相移动、至少一个停止点预测 | 第二个同类预测、友军观察可选 |
| T4 | 多目标路径、隐身马接触 | 阵亡虚影观察与结果选择题可选 |
| T5 | 区域轰炸、弹药/友伤反馈 | 普通炮吃子演示 |
| T6 | 取消献祭、确认献祭、候选池反馈 | 九宫普通斜走 |
| T7 | 帅入攻击范围、实际吃将 | 结果选择题 |
| T8 | 破墙、直接进营拒绝、缓冲区→大本营 | 修复过程只观察说明，不要求完整等待 |
| T9 | 发现旗帜、离开视野后的记忆 | 完整 3/3 占领演示，由 T10 实践验证 |
| T10 | 全部综合目标 | 无 |

如果玩家在综合考核中暴露某项理解问题，对应能力变为 `NEEDS_REVIEW`，完成页直接提供该模块的完整切片入口。

## 10. 教学提示与反馈

### 10.1 默认提示档

| 档位 | 基础路线 | 差异路线 |
|---|---|---|
| 初始 | 目标文字、相关棋子轻提示、合法点 | 目标文字，不给唯一棋子或目标点 |
| 第 1 次无效 | 公开规则原因，不消耗行动 | 同左 |
| 第 2 次无效 | 高亮起点、路径或机制区域 | 高亮相关机制区域，不标唯一答案 |
| 第 3 次无效 | “查看演示”按钮 | “查看演示”按钮 |
| 第 4 次及以后 | 保留演示并提供重置本步骤 | 同左 |

### 10.2 文案结构

每一步只使用：

- **目标**：现在要达成什么；
- **原因**：为什么值得做；
- **结果**：刚才发生了什么。

示例：

- 目标：**让第三枚红子进入黑方缓冲区。**
- 原因：**三枚入侵者会压垮这段城墙。**
- 结果：**城墙已破，敌方区域进入视野；隐身单位仍需显形原因。**

### 10.3 非法与偏离目标行动

- 规则非法：显示正式 `VisibleError` 的公开原因，不消费行动。
- 规则合法但不符合当前目标：允许预览；确认前提醒“这不会推进当前军令”。
- 玩家仍确认偏离行动：在可恢复模块中允许观察结果并提供“回到本步骤检查点”；不得伪造该行动非法。
- 会破坏固定教学条件的自由行动：通过预置局面和任务目标减少出现概率，不能靠读取隐藏事实临时封锁。

## 11. 失败、重置、跳过与恢复

### 11.1 能力状态

每个能力使用以下状态：

- `UNSEEN`：未接触；
- `ASSUMED`：玩家因选择差异路线而自报掌握；
- `COMPLETED`：已通过行动证据；
- `SKIPPED`：玩家明确跳过；
- `NEEDS_REVIEW`：综合考核暴露相关理解问题。

`ASSUMED`、`SKIPPED` 和 `COMPLETED` 不得混为同一状态。

### 11.2 失败条件

普通模块没有惩罚性失败，只记录无效尝试并允许步骤重置。

综合考核在以下情况失败：

- 八个己方行动用尽；
- 占领者离开、死亡或献祭，且已无法在剩余行动内恢复；
- 己方帅实际死亡；
- 固定脚本到达预设终止条件。

失败只重置当前综合考核，不清除其他能力状态。

### 11.3 跳过

- 章节和模块均可跳过；首次跳过弹出一次后果说明。
- 跳过记录为 `SKIPPED`，不伪装为完成或胜利。
- 综合考核允许跳过，但目录显示“未验证”，局域网入口不被锁死。
- 玩家进入局域网前，如果关键能力仍为 `UNSEEN/SKIPPED`，只显示一次非阻断提醒。

### 11.4 跨会话恢复

本地进度保存：

- `schema_version`；
- 选择的路线；
- 各能力状态；
- 已完成和已跳过模块；
- 最近路线章节和公开检查点；
- 综合考核最佳公开结果：行动数、无效次数、提示档。

不保存 FullState、隐藏旗位、权威随机内部状态或未完成对局。恢复时重新创建固定 Scenario，再导航到已确认的公开检查点。

## 12. UI 与交互规格

### 12.1 关卡目录

目录结构：

```text
新手教学
├─ 从基础学起  A0–A7
├─ 只学《雾疆》差异  X0–X4
└─ 全部模块复习  P0 / T0–T10 / B1–B3
```

每张路线卡显示：适用玩家、预计时间、完成比例和“可随时切换”。

路线章节卡显示能力完成比例，不显示模块内部技术 ID。

### 12.2 对局内 HUD

继续复用正式 Match HUD 和行动确认面板。教学只增加预置 `TutorialOverlay`：

- 收起态：章节名、当前目标、进度；
- 展开态：原因、规则图例、提示和重置；
- 完成态：本章掌握内容、下一章、留在本章、返回目录；
- 失败态：公开失败原因、重试、返回目录。

棋子信息抽屉显示两个独立区块：

- 普通行动；
- 《雾疆》特殊行动及当前资格原因。

不得用同一个高亮颜色同时表示合法落点、车路径、相田、炮击风险和教程目标。颜色必须辅以线型、形状或图标。

### 12.3 输入与可访问性

- 支持鼠标、键盘确认/取消和现有桌面输入。
- 关键按钮最小可点击高度 44 像素。
- 在 960×540、1280×720、1920×1080 下完成布局检查。
- 文字可滚动但目标和确认按钮保持可见。
- 颜色信息必须有图形冗余；迷雾、旗帜记忆、相田和车路径不能只靠色相区分。

## 13. 声音与视觉反馈

灰盒阶段只定义功能反馈，不冻结最终资产：

- 第一次揭雾：短促风声与旗铃，强调发现而非奖励弹窗。
- 合法行动预览：轻量线条与落点反馈，不播放结算音。
- 确认行动：棋子落点声；吃子、破墙、轰炸、献祭各有不同事件层级。
- 公开拒绝：低强度木鱼/军令牌反馈，避免刺耳错误音。
- 能力完成：在棋盘结果出现后再显示图章，不遮挡行动。

任何音效不得泄露未进入当前 PlayerView 的棋子、旗位、炮击结果或敌方意图。

## 14. Godot 数据与场景方案

固定界面和结构继续优先使用预置节点与 Resource。

### 14.1 新增 Resource

`TutorialRouteDefinition`：

- `route_id`：`foundation` / `xiangqi_experienced`；
- 标题、说明、目标时长；
- 预置章节引用数组；
- 默认提示档；
- 自报掌握的能力 ID；
- 完成后推荐入口。

`TutorialRouteChapterDefinition`：

- 稳定章节 ID：A0–A7 或 X0–X4；
- 标题、摘要、预计时间；
- 按序引用的模块 ID，以及每项预置的起始步骤、完成步骤和提示档；
- 进入条件和完成能力集合；
- 是否综合考核。

`TutorialModuleDefinition`：

- 稳定模块 ID；
- 权威 `TutorialScenarioDefinition`；
- `TutorialPresentationTrack`；
- 能力 ID；
- 可用公开步骤切片及依赖声明；
- 正向、负向和重置验收标签。

### 14.2 复用与迁移

- T0–T10 的 authority/presentation Resource 继续复用。
- 新增 P0、B1、B2、B3 四个模块 Resource。
- `TutorialChapterCatalog` 从硬编码 T0–T10 数组迁移为预置 `TutorialModuleCatalog` Resource。
- `TutorialDirector` 仍只消费 PlayerView、VisibleEvent、VisibleError、ActionPreview、准备/取消/重置回执。
- 路线编排由 `TutorialRouteDirector` 或现有 Director 的窄扩展负责；它只选择下一个模块，不拥有规则状态。
- 路线选择、章节卡、Overlay、完成页均使用预置场景与容器；只对目录卡片和棋盘数据对象进行必要的运行时实例化。

### 14.3 权威与信息边界

- Scenario 只在行动索引 0 前建立固定局面。
- 玩家和脚本对手的所有正式行动都提交规范化 Intent，并由同一规则核心结算。
- 教学提示不得读取 FullState、权威随机、未发现旗位或未显形棋子。
- 固定种子只用于可重放结果，不能下发给可据此反推隐藏事实的表现层。
- 重试创建新的权威教学会话，不直接修改棋盘节点。

当前 `step_effects / apply_tutorial_transition` 仅可视为灰盒兼容债务。本提案不批准扩展直接状态改写；进入正式双轨生产时，应把玩家行动、脚本行动和教学结算逐步迁移到正式 Intent/Event 管线。

## 15. 测试与验收

### 15.1 自动化合同

必须新增或修订：

1. 两条 RouteDefinition 引用的章节和模块全部存在，ID 唯一。
2. 每个能力至少有一个正向通过证据；关键规则至少有一个公开拒绝或预测证据。
3. 差异路线不加载 B1–B3，但基础走法抽屉仍可访问。
4. 路线切换正确合并 `ASSUMED/COMPLETED/SKIPPED`，不丢失完成记录。
5. P0 首次有效行动可以在一次选择、一次预览、一次确认后完成。
6. T6 取消不消耗行动，且不会自动跳回再次献祭。
7. T10 两种提示档均可完成；八行动失败、占领中断和帅死亡正确重置。
8. 隐藏等价 FullState 产生相同提示、可见高亮和模块推进结果。
9. 三档分辨率、键盘焦点、返回、暂停、重试和跳过全部通过。
10. 教学正式目录不依赖 prototype 或完整 AI 模块。

### 15.2 人工灰盒试玩

最低样本：

- 5 名从未玩过或说不清基本走法的玩家；
- 5 名会基本走法的象棋玩家；
- 测试者不得在过程中口头解释规则，只记录卡点。

记录：

- 第一次有意义行动用时；
- 每模块用时；
- 首次成功/重试次数；
- 最高提示档；
- 退出点与跳过点；
- T10 行动数、失败原因和是否使用三级提示；
- 传统经验误判类型；
- 结束后能否用自己的话解释胜负与两种特色机制。

### 15.3 初步通过门槛

- 至少 80% 测试者在无口头协助下完成所选路线。
- 两组玩家的第一次有意义行动中位数不超过 30 秒。
- 基础路线中位完成时间不超过 35 分钟；差异路线不超过 18 分钟。
- 至少 70% 测试者在最多一次重试内通过 T10。
- 差异路线完成后，不再有测试者把将军/飞将当作强制规则。
- 零基础玩家能正确描述至少五类棋子的普通行动；其余两类可借助信息抽屉回忆。
- 自动化隐藏等价、重置一致性和三档布局测试全部通过。

若样本量不足，上述数据只用于方向判断，不声称具有统计代表性。

## 16. FTUE 与心理需求自检

### 16.1 体验阶段

- **框架**：教学覆盖从首次进入到完成第一面战旗，不把 T0 操作说明误当作全部 FTUE。
- **召唤**：P0 用失联烽讯和战旗发现建立目标，避免先读棋子百科。
- **导师**：军令使只提供目标、原因和结果，不成为连续文本框。
- **跨越门槛**：前两分钟内出现一次自主选择；T10 要求玩家在少提示状态下独立组合规则。

### 16.2 心理需求

- **自主感**：自选路线、可换路线、可选择破常模块顺序、合法偏离行动可预览。
- **胜任感**：基础与特殊能力分层；失败逐级提示；综合考核回顾具体行为，不评价人格或天赋。
- **关联感**：以接掌军队、恢复烽讯和夺回战旗作为最小情境，由军令使提供稳定但克制的陪伴。

### 16.3 当前弱点

- P0 的情境和军令使身份尚未经过玩家验证，可能仍显得像包装后的操作提示。
- 差异路线信息密度仍高，12–18 分钟目标必须靠真实试玩验证，不能仅按步骤数宣称达成。
- T10 固定局面如果只有唯一解，仍可能形成“猜策划答案”；灰盒应至少验证两条合法解法，或明确它是一项固定战术考核。
- 当前实现中的直接 `step_effects` 会削弱“真实行动”感，在正式验收前必须收敛。

## 17. 主要流失风险与对策

| 风险 | 主要受影响玩家 | 对策 |
|---|---|---|
| 开场先读大量规则 | 两组 | P0 先行动，规则在结果后出现 |
| 基础和特殊规则同时灌输 | 零基础 | B1–B3 与 T1–T7 分层 |
| 重复基础走法导致无聊 | 象棋玩家 | 差异路线跳过基础模块并用反直觉行动开场 |
| 一路按箭头，实战崩溃 | 两组 | T10 少提示综合考核 |
| 教程合法性与正式规则漂移 | 两组/生产 | 同一 Intent/Event/PlayerView，禁止第二套规则 |
| 提示泄露隐藏棋子或旗位 | 两组 | Director 只消费观察者安全 DTO，做隐藏等价测试 |
| 跳过被当作完成 | 两组 | `SKIPPED` 与 `COMPLETED` 分离 |
| 换路线后重复或丢进度 | 两组 | 以能力状态合并，不按章节布尔值覆盖 |
| 导师成为文本框 | 两组 | 每步只给目标、原因、结果，百科按需展开 |

## 18. 生产拆分建议

### 阶段 1：双轨 HTML 灰盒

- 新增路线选择、A/X 章节目录和能力进度模拟。
- 用现有 T0–T10 文案重组路线；P0、B1–B3 先做低保真脚本局面。
- 验证两条路线的顺序、目标时长和跳过/换路线。

### 阶段 2：Godot 路线与进度骨架

- 新增三个 Resource 类型和预置路线选择界面。
- 升级进度 schema，保留旧 T0–T10 完成记录的兼容迁移。
- 先用现有模块跑通两条路由，不立即制作新基础局面。

### 阶段 3：P0、B1–B3 正式模块

- 为四个新模块建立权威 Scenario、表现 Track 和自动化测试。
- 接入正式 PlayerView 和行动管线。
- 完成基础路线闭环。

### 阶段 4：正式规则迁移与双轨验收

- 收敛 `step_effects` 灰盒债务，不再扩展直接状态变更。
- 跑隐藏等价、重置、确定性、布局和完整路线回归。
- 完成两组人工试玩并根据退出点压缩内容。

## 19. 项目所有者批准项

在进入 Godot 双轨生产前，需要项目所有者确认：

1. 采用“两条入口、一套共享模块”的总体结构；
2. 基础路线 25–35 分钟、差异路线 12–18 分钟的目标区间；
3. 新增 P0、B1、B2、B3 四个模块；
4. 将 T0–T10 从用户可见单线关卡重组为路线内部模块；
5. 使用 `ASSUMED/COMPLETED/SKIPPED/NEEDS_REVIEW` 能力状态；
6. 综合考核允许跳过，但显示“未验证”且不阻断局域网入口；
7. “军令使”仅作为灰盒文案身份，不冻结角色美术或配音。

未获批准前，本文件保持提案状态，不替换 v2，不修改生产 Registry，也不启动高成本美术或正式双轨实现。
