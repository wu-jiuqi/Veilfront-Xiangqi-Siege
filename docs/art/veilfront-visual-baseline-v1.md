# 《雾疆：九路烽棋》视觉实现基线 v1

状态：`owner_direction_frozen / preproduction_only / pending_gate2`

适用工作项：`LOOP-GATE2-001 / ITERATION-3-TUTORIAL-VISUAL / TASK-ART-001`

权威来源：`codex-thread://current#owner-freeze-oblique-3d-board-art-direction`

## 1. 冻结结论

《雾疆》正式替换原有 90° top-down 2D 俯视表现，采用以下组合：

```text
一基 Vector2i 规则交点（X=1..9, Y=1..24）
  → 观察者安全 PlayerView
  → Node3D 三维棋盘与结构物
  → Sprite3D / AnimatedSprite3D 二维角色
  → 锁定旋转的低 FOV 斜俯视透视摄像机
  → CanvasLayer + Control 固定界面
```

本文件冻结技术方向与资产制作口径，不代表 GATE-2 已通过，也不授权全套棋子动画、完整音频、全量特效、最终 UI 皮肤或高成本外包。

## 2. 不可变边界

- 正式棋盘为 24×9 交点，共 216 点；权威坐标始终为 `X=1..9, Y=1..24`。
- 规则、回放、随机消费、教学和未来网络同步不得使用 `Vector3`、节点位置、Tween 进度或摄像机状态。
- Presentation 只消费观察者安全的 `PlayerView`、`VisibleEvent`、`ActionPreview` 与只读美术资源。
- 未授权敌棋、未发现旗位和其他隐藏事实不得仅靠视觉遮挡；对应表现节点不得创建。
- 红黑视角只改变显示映射和摄像机朝向，不改变权威坐标、Intent 或行动语义。
- 固定结构优先使用 `.tscn`、`.tres` 和 Inspector 预置节点；仅数量或生命周期由对局数据决定的对象允许运行时实例化。

## 3. 棋盘与世界尺度

| 项目 | 冻结值 |
|---|---|
| 交点 | 9 路 × 24 线 |
| 坐标 | `X=1..9, Y=1..24` |
| 相邻点距 | `1.2` 世界单位 |
| 网格覆盖 | `9.6 × 27.6` 世界单位 |
| 底板建议 | `11.4 × 0.22 × 29.4` 世界单位 |
| 世界轴 | X=九路横向，Y=高度，Z=24线长轴 |
| 网格表现 | 单张精确透明纹理覆盖层；不得由生成式图片直接生成线条 |

棋盘底板优先使用薄 `BoxMesh` 或正式 `.glb` 静态网格。网格、区域底色和墙线必须分别可控；Y=4/Y=21 城墙是结构物，不是区域分割线。

## 4. 摄像机基线

| 参数 | 冻结目标 |
|---|---|
| 投影 | Perspective |
| 俯角 | 名义 50°；样片校准允许 45°～55° |
| FOV | 30°；允许 28°～32°校准 |
| 水平角 | 0°；另一方视角为 180° |
| 游戏中旋转 | 禁止自由旋转 |
| 允许操作 | 长轴平移、有限缩放、双方视角切换 |
| 构图要求 | 九路宽度始终完整显示，24线沿长轴浏览 |

50°作为首个样片值，用于降低 45°下前排角色遮挡后排的风险。最终数值只允许在上述校准带内调整；越界视为基线变更。

## 5. 棋子表现

- 默认节点：`Piece3D(Node3D) → VisualPivot(Node3D) → Sprite3D`。
- 默认朝向：`BILLBOARD_FIXED_Y`。所有棋子采用面向玩家的战棋立牌语言；阵营朝向不依赖纸片背面。
- 普通步兵世界高度：`1.45～1.70`；骑兵：`1.80～2.10`；战车/器械：`1.90～2.20`。
- `Shaded=false`、`No Depth Test=false`、`Cast Shadow=Off`、`Fixed Size=false`。
- 默认透明模式为 Opaque Pre-Pass；只有样片证明软边质量或排序不达标时，才比较 Alpha Hash。
- 每枚棋子使用预置水平椭圆假阴影；不得让 Billboard 直接投射实时阴影。
- 身体点击需要时使用 `Area3D → CollisionShape3D`；碰撞对象只返回棋子 ID 或逻辑交点，不拥有规则状态。
- 首轮样片使用静态立绘与 Tween；完整序列帧动画留在 GATE-2 后的批量生产合同。

## 6. 迷雾与信息层

- 使用一份全局 `9×24` 观察者安全 mask，由 PlayerView 的 `visible_cells` 更新。
- mask 通过单一 `SubViewport` 或等价 CPU 图像生成纹理，再由棋盘上方的 `ShaderMaterial`/覆盖平面采样；禁止为 216 点创建 216 个节点。
- 当前可见区域透明，入雾区域为黑蓝半透明；边缘只做视觉柔化，不扩大真实可见范围。
- 已发现旗帜记忆、己方阵亡虚影和私人标记使用各自授权字段绘制，不能从雾层推导。
- 迷雾、镜头、音效、粒子与合法落点不得泄露未出现在 PlayerView 中的敌棋或旗位。

## 7. 灯光、材质与渲染器

- 目标渲染器：Forward+，面向 Steam 桌面端；当前 Compatibility 配置保留到技术样片完成，不在文档冻结阶段直接改写项目设置。
- 世界：一个 `DirectionalLight3D`、一个 `WorldEnvironment`，棋盘和结构物受光。
- 角色：不受实时三维灯光影响，通过统一调色、边缘暗化和脚下假阴影融入场景。
- 不把体积雾、SDFGI、SSR 或 AreaLight3D 作为核心可读性的必要条件；样片在关闭高级效果时仍须成立。
- 地面、城墙和大型结构以 `StandardMaterial3D/ORMMaterial3D` 为主；自定义 Shader 只用于迷雾、阵营调色和交互反馈。

## 8. 视觉语言

关键词：`东方战争奇幻 / 军阵沙盘 / 青铜与漆器 / 烽火烟尘 / 克制修仙 / 强轮廓 / 高信息可读性`。

基础色板：

| 用途 | 色值 |
|---|---|
| 战场土色 | `#6F5133` |
| 旧青铜 | `#5C513C` |
| 雾与深阴影 | `#0B1014` |
| 红方主色 | `#B84436` |
| 黑方主色 | `#2F3B49` |
| 修仙/侦察强调 | `#4FA79A` |
| 旗帜/目标金色 | `#D5AC62` |

- 环境低饱和，交互、阵营和目标高于环境饱和度。
- 修仙元素作为局部能量纹、符箓、玉色光和粒子强调，不覆盖战争装备的材质识别。
- 棋子首先依靠轮廓与兵种道具识别，其次才依靠颜色；禁用只换色不换轮廓的兵种方案。
- 区域仍使用材质/色相和不越界的大字区分，不增加额外区域分割线。

## 9. 源资产与运行时规格

| 类型 | 源文件 | 运行时目标 |
|---|---|---|
| 直立棋子 | 1024×1536 透明 PNG/PSD | 最大 512×768，VRAM Compressed，mipmap 开启 |
| 宽体棋子 | 1536×1536 透明 PNG/PSD | 最大 768×768，VRAM Compressed，mipmap 开启 |
| 棋盘/结构模型 | Blender 源文件 | `.glb`，生成 LOD，静态对象按需 Light Baking |
| 网格与图标 | SVG/PSD/PNG 源文件 | 透明 PNG 或 Texture2D；3D表面纹理开启 mipmap |
| UI | SVG/PSD/Figma 源文件 | UI纹理无 mipmap，图标优先矢量源 |
| 音效 | 48kHz WAV 源文件 | 短 SFX 使用 WAV；环境/音乐使用 OGG |

透明角色必须保留 8～16px 安全边距、透明像素下的颜色扩展、统一脚底线和统一构图中心。禁止把 1024×1536 直接作为每帧运行时动画规格。

## 10. 首轮样片验收

首轮只验证：棋盘底板、网格、城墙、步兵、骑兵、旗帜、迷雾、选择环、合法落点和一次攻击反馈。

必须在 `960×540 / 1280×720 / 1920×1080` 验证：

- 九路完整、长轴平移边界正确、点距投影清晰；
- 前后排棋子在默认缩放下可区分，不能连续遮住两个以上交点；
- 红黑视角切换后己方大本营在底，交互坐标不变；
- 棋子与城墙、地表、雾和特效的深度关系稳定；
- 未授权棋子和旗位没有节点、像素、音效或镜头泄露；
- 关闭高级后处理后，棋盘、棋子和交互反馈仍可读；
- 1280×720 下普通棋子屏幕高度建议保持 96～180px。

## 11. 变更控制

以下内容已经冻结：二维规则/三维棋盘分层、24×9一基坐标、Sprite3D角色、斜俯视低FOV镜头、锁定旋转、PlayerView信息边界、预置节点优先。

以下内容只允许在样片校准带内调整：俯角、FOV、棋子世界高度、假阴影尺寸、雾边缘软度、单个色值亮度。

以下变化必须重新进入视觉基线审查：恢复90°纯俯视、自由旋转、改为全3D角色、改变棋盘坐标/点距语义、让客户端持有隐藏节点、以高级渲染特性作为可读性前提。
