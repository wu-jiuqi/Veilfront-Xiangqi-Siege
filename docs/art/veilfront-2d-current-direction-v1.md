# 《雾疆：九路烽棋》当前二维表现方向 v1

状态：`owner_confirmed / contract_v3_active`

## 1. 当前主线

现阶段正式实现改为 Godot 2D：规则继续使用一基 `Vector2i` 交点坐标；正式战场使用 `Control/Node2D`、`Sprite2D/AnimatedSprite2D`、二维迷雾与二维战术反馈。固定界面和布局优先使用编辑器预置场景、容器、Theme 与资源，不以脚本动态拼装固定结构。

主棋盘保持 24×9 交点、九路完整显示和沿长轴浏览；红黑双方都令己方大本营位于画面底部，黑方只做 180°二维表现映射，不修改权威坐标、规则或行动语义。

表现层只消费当前观察者的 `PlayerView`。未授权敌棋、未发现旗位及其碰撞、提示、粒子或音效来源不得创建表现节点。教学继续经由同一 Intent/Event 与规则核心运行。

## 2. 后期可选项

斜俯视 Node3D 战场、Sprite3D/AnimatedSprite3D 棋子和三渲二方案转为项目后期进阶可选项。只有在二维主线稳定、另立范围并获得项目所有者批准后，才能重新进入生产或验收。

既有 14 枚兵马俑静态棋子、三维测试场、镜头与旗帜样片作为历史研究资产保留，不删除、不伪装成当前交付，也不作为当前 GATE-2 的功能、性能或视觉验收前置。

## 3. 当前二维 GATE-2 最小基线

- 预置二维正式对局壳与教学壳；
- 精确 24×9 交点棋盘、区域底色/纹理和二维城墙状态；
- 红黑双方 180°表现映射、交点点击、选择、移动、攻击与确认反馈；
- 只消费 `PlayerView` 的观察者安全迷雾、棋子和旗帜表现；
- 960×540、1280×720、1920×1080 的响应式主棋盘与 HUD；
- 二维棋子、旗帜、城墙、迷雾、高亮和局部 UI 样片；
- 规则、PlayerView、回放和教学语义不因表现层变化而改变。

## 4. 当前禁止扩展

- 不继续生产或接入新的三渲二/三维资产；
- 不把既有 Sprite3D 测试场升级为当前正式对局壳；
- 不启动完整动画、音频、全量 VFX、最终 UI 皮肤或外包预算承诺；
- 不实现互联网传输、Steam SDK、服务器、匹配、重连或 AI 人机对战；
- 不修改 owner rule revision 5、PlayerView、回放摘要、随机消费与教学语义。
