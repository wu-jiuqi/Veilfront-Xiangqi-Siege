# 《雾疆：九路烽棋》全量 UI 重构规范 v1

日期：2026-09-02  
基准画布：1280×720  
适配范围：960×540、1280×720、1920×1080、21:9

> 状态：布局与可访问性基线继续有效；视觉材质和开始菜单保护边界由 `ui-stylized-visual-direction-v2.md` 覆盖。

## 重构结论

除开始菜单外，正式 UI 只保留一套“玄铁军帐”组件语言。开始菜单保留原版朱土主题和青铜剑按钮。背景美术负责场景气氛，Theme 负责其他正式页的可交互表面；固定尺寸整页贴图不承担布局定位。页面使用预置 `Control` / `Container` 节点组成，并通过统一安全区、间距、字体和状态反馈消除错位。

## 页面网格

- 核心安全画布为 1280×720，超宽屏只延展背景。
- 普通页面安全边距 32 px；对局 HUD 安全边距 16 px；960×540 紧凑模式允许降为 16 px / 12 px。
- 间距只使用 4、8、12、16、24、32、48 六档。
- 顶栏高度 72 px；普通按钮 52 px；主操作按钮 60 px；紧凑按钮 44 px。
- 正文不低于 16 px；辅助信息不低于 14 px；可交互文字不低于 16 px。

## 表面层级

| 变体 | 用途 | 视觉角色 |
|---|---|---|
| `PageSurface` | 页面主框 | 近黑玄铁、2 px 青铜边 |
| `PrimarySurface` | 核心任务区 | 深铁色、强调顶边 |
| `SecondarySurface` | 侧栏/卡片 | 更安静的铁灰 |
| `InsetSurface` | 文本、状态、输入 | 下沉黑色衬底 |
| `OverlaySurface` | 模态、教程、结算 | 高不透明表面与清晰轮廓 |
| `DangerSurface` | 失败与危险确认 | 铁红边线，不使用金色奖励反馈 |

复杂纹样与角花可以进入带有效 patch margin 的九宫格 `StyleBoxTexture`，但只能占据边框和角部；不得拉伸穿过正文。全屏气氛美术仍应作为 `TextureRect` 子层并设置 `mouse_filter = IGNORE`。

## 按钮家族

- `PrimaryButton`：页面唯一主要推进操作。
- `ConfirmButton`：准备、进入关卡、应用、继续等确定性动作。
- `SecondaryButton`：返回、取消、普通操作。
- `GhostButton`：页签、轻量工具、无强调操作。
- `DangerButton`：退出、重置、断开、失败恢复中的危险动作。
- `CompactButton`：HUD 紧凑操作，最小高度仍为 44 px。

按钮与所在面板共享同一圆角、边框颜色和材质明度。Hover、Focus、Press 只改变亮度、边线和轻微视觉位移，不更换完全不同的贴图轮廓。减少动态效果开启后仅保留 80–120 ms 色彩变化。

## 排版层级

- `DisplayTitle`：32–40 px，只用于页面标题。
- `ScreenTitle`：28 px，页面或模态标题。
- `SectionTitle`：20 px，面板标题。
- `BodyText`：16 px / 建议 24 px 行距。
- `SecondaryText`：14 px，仅承载辅助信息。
- `NumericText`：20–28 px，用于回合、进度、房间号等。

正文统一使用 Noto Sans SC。行书仅可用于 28 px 以上的气氛标题，不能用于按钮、表单或规则正文。

## 页面骨架

- 主菜单：保护原版双字标、方印、雾幕与青铜剑按钮构图，不接入 V2 Theme。
- 关卡选择：72 px 顶栏；左侧 220 px 分类与进度；中部弹性关卡网格；右侧 300 px 详情与主操作。
- 联机房间：72 px 顶栏；左房间信息、中对阵席位、右规则；底部固定状态与动作栏。
- 设置：居中 760 px 设置面板；设置行 60 px；页脚动作固定，不留大块无功能空白。
- 对局 HUD：顶部回合条；左 240 px 战况；中部棋盘；右 300–360 px 目标/教学抽屉；底部行动条。
- 教程图鉴：居中 1120×640，上方标题、左图右文、底部翻页，960×540 时保持可滚动。
- 加载/失败/结算：同一 `OverlaySurface`，主标题—正文—状态—动作四段垂直结构。

## 验收

- 不存在由固定尺寸按钮/面板贴图内容边距造成的文字偏移；九宫格边框必须拥有有效 patch margin。
- 页面节点以 `Container` 和预置场景为主，禁止按分辨率逐控件脚本定位。
- 960×540 下核心文字不裁切，所有按钮高度至少 44 px。
- 1280×720、1920×1080 和 21:9 下核心功能区比例稳定。
- 键鼠与手柄均可沿显式焦点链完成主流程。
- UI 重构不得改变规则、PlayerView、教程语义、联网协议或随机消费。
