# 《雾疆：九路烽棋》风格化 UI 视觉方向 v2

日期：2026-09-02  
适用范围：除开始菜单外的正式功能页、对局 HUD、教程与系统模态框  
视觉命题：**玄铁军帐 / 兵书军令**

> 状态：材质命题保留；信息层级、装饰预算、颜色与字体规则已由 `ui-ux-information-architecture-v3.md` 覆盖。v3 明确减少内层复杂边框，并限制书法字体的使用范围。

## 保护边界

开始菜单不参与本轮改造。`start_screen.tscn` 与 `start_menu_overlay.tscn` 继续使用原版朱土主题、金色双字标、方印与青铜剑按钮；静态合约和前台冒烟测试共同锁定这条边界。

## 视觉识别

界面不再是通用深色工具面板，而是由漆黑玄铁、旧青铜包边和军令牌构成的东方战争奇幻器物。页面主框像一块可展开的战术案板；二级框像铆接在案板上的铁片；模态框像置于棋局上方的军令匣。

主色与语义：

- 玄铁黑：页面底色和下沉区域，承担信息稳定性。
- 旧青铜：边框、铆钉、标题和焦点，承担秩序与权威感。
- 玉石绿：确认、继续、准备和可安全推进的操作。
- 朱砂红：危险、失败、退出和不可逆操作。
- 暖象牙：正文与关键数值，避免纯白造成的现代软件感。

## 材质与层级

| Theme 变体 | 角色 | 材质表达 |
|---|---|---|
| `PageSurface` | 页面最外层 | 大型玄铁军案框，旧青铜包边 |
| `PrimarySurface` | 核心任务区 | 铆接铁框，视觉权重最高 |
| `SecondarySurface` | 侧栏、卡片 | 较暗的铁片框，弱化竞争 |
| `InsetSurface` | 输入、状态、正文槽 | 下沉漆黑内槽，不使用繁复纹样 |
| `OverlaySurface` | 图鉴、结算、系统模态 | 对称军令匣框，四角装饰完整 |
| `CalloutSurface` | 当前目标、步骤提示 | 青铜强调内框，适合短文本 |
| `WarningSurface` | 教程易错点、警示 | 朱砂与铜色并置，不等同失败 |
| `DangerSurface` | 失败、危险确认 | 深朱砂包边，禁止使用玉色确认语义 |
| `PauseOverlaySurface` | 暂停菜单 | 为顶部纹章预留呼吸区的军令匣框 |

九宫格材质只负责可缩放的边框与角饰，布局尺寸仍由预置 `Control` / `Container`、安全边距和内容最小尺寸决定。禁止使用固定尺寸的整页截图承载控件布局。

## 按钮语言

按钮统一表现为嵌入面板的金属军令牌，并与所在面板共享青铜边与玄铁明度。

- `PrimaryButton`：单页唯一主推进操作，金铜强调。
- `ConfirmButton`：玉色金属牌，用于进入、准备、应用、继续。
- `SecondaryButton`：玄铁牌，用于普通操作和返回。
- `GhostButton`：低对比铁片，用于页签与轻量工具。
- `DangerButton`：朱砂牌，用于退出、断开、重置。
- `CompactButton`：HUD 紧凑军令牌，交互高度仍不低于 44 px。

Hover 提升边线和材质亮度；Pressed 产生轻微下压；Focus 始终保留独立金色轮廓；Disabled 降低饱和与对比，但不能只靠透明度隐藏状态。

## 字体与信息层级

- 页面标题、章节标题与关键数值使用 `QynFlavorGroteskAltCHS`，形成碑刻/军令标题感。
- 正文、规则、按钮和表单使用 Noto Sans SC，优先保证长文本可读性。
- `DisplayTitle` 40 px、`ScreenTitle` 30 px、`SectionTitle` 22 px、正文 16 px、辅助信息 14 px。
- 960×540 下不继续缩小核心字号，改由布局进入紧凑模式或滚动容器承载。

## 构图规则

- 页面只允许一个最强外框，内部用主框、次框、内槽三级组织信息，避免每个控件都抢夺装饰权重。
- 装饰纹样只能出现在边框、角部和标题附近，不得穿过正文或按钮文字。
- 标题、内容、动作之间保持 16–32 px 的稳定节奏；模态框顶部纹章区域单独预留空间。
- 对局 HUD 的左右栏与棋盘边框共享材质语言，但中心棋盘始终保持最高可读性。
- 960×540、1280×720、1920×1080 与 21:9 共用同一套预置节点，不按分辨率脚本逐控件定位。

## 验收底线

- 开始菜单视觉与交互资产保持原样。
- 面板与按钮必须属于同一材质体系，不出现网页式纯色卡片拼接。
- 九宫格边距必须有效，任意正式分辨率下角饰不得拉伸、正文不得压在纹章上。
- 所有可见按钮高度至少 44 px，并具备 Hover、Pressed、Focus、Disabled 状态。
- 风格化不得改变规则、PlayerView、教程语义、联网协议、随机消费或音频事件语义。
