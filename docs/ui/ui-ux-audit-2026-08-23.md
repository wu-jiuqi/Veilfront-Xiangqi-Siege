# 《雾疆：九路烽棋》UI/UX 审查与优化方向

日期：2026-08-23
基线：Godot 4.7.1，1280×720 桌面画布
范围：主菜单、设置、关卡选择、联机房间、正式战局 HUD、教学 HUD、加载失败、结算页

## 结论

当前项目已经形成统一的玄铁、青铜与军帐美术语言，联机房间和结算页的视觉完成度尤其高。主要问题不在于“缺少装饰”，而在于装饰层级明显高于信息层级：正文过小、文字与暗背景对比不足、关键按钮缺少跨页面一致的确认反馈，以及少数页面把大量空间留给边框或空面板。

建议先修两项 P0：正式战局与教学信息的可读性，以及教学右栏的拥挤/遮挡；之后再统一按钮动效、字体角色和低分辨率布局。

## 审查证据

- 使用当前工作区内容，通过 Godot 4.7.1 重新捕获主菜单、设置、关卡选择与正式战局 1280×720 画面。
- 复核联机房间、加载失败、结算页和多分辨率历史证据。
- 静态检查 UI 场景、主题、焦点链、字体资源、按钮实例和 Tween 实现。
- 当前仅有两套中文字体：`Noto Sans SC Variable` 与 `ramega 张青平行书`。
- 当前正式 HUD 存在 10–14 px 的信息文字；教学层存在 9–12 px 的正文/提示文字。

## 问题清单

| 优先级 | 区域 | 问题 | 影响 | 建议 |
|---|---|---|---|---|
| P0 | 正式战局 HUD | 阵营统计、目标列表、单位信息大量使用 10–14 px；暗金与灰绿文字压在高纹理背景上 | 视线必须离开棋盘并停留阅读，直接打断回合决策 | 核心正文提升到 15–16 px，次级信息不低于 14 px；目标行用更深的纯色衬底，降低边框纹理亮度 |
| P0 | 教学 HUD | 教学正文 9–12 px，右栏同时承载目标、步骤、滚动条和燃香组件；滚动区横向空间不足 | 新玩家最需要读懂的信息反而最难读，且容易误以为内容被截断 | 教学信息改成独立的 360–400 px 教学抽屉；正文 16 px、辅助 14 px；燃香只保留细窄计时条或移到顶部 |
| P1 | 主菜单 | 剑形按钮轮廓比文字更亮；默认文字接近背景，当前只有主题颜色切换，没有统一按钮补间 | 可点击性与当前焦点不够明确 | 默认文字亮度提高约 20%；悬停 6 px 出鞘位移 + 1.025 缩放；按下 0.965；焦点显示连续金线 |
| P1 | 设置页 | 三个画面选项只占内容区上半部，中心出现大片无功能空白；状态提示离控件过远 | 信息密度低，用户难以建立“改了什么—在哪里应用”的因果 | 内容框收窄并改成 620–680 px 的设置列；状态提示贴近页脚操作；每行 56–64 px |
| P1 | 设置页动效 | 当前场景中的 5 个 `UiMotionButton` 把 `motion_profile` 覆盖为 `null`；脚本仍有 fallback，但脱离统一 profile | 后续统一调参、减少动态效果和动效分级更难维护 | 清除实例级 `null` 覆盖，恢复共享 `terracotta_ui_motion_profile.tres`；给“应用”和危险操作增加独立反馈组 |
| P1 | 关卡选择 | 右侧说明与底部快捷键 13–15 px，低对比；关卡节点靠贴图瞬间切换状态 | 信息完整但阅读优先级弱，选择过程缺乏路线推进感 | 说明正文 16 px，次要信息 14 px；节点选择时 180 ms 光环与路线点亮；快捷键改为清晰键帽组 |
| P1 | 跨页面按钮 | 主菜单、关卡、联机、教学和结算分别使用普通 Button、TextureButton 与 `UiMotionButton`，反馈语言不一致 | 同样的“确认”动作在不同页面手感不同 | 以预置 `UiMotionButton` 为基础扩展 Primary / Secondary / Danger / Confirm 四个预置变体 |
| P1 | 焦点导航 | 除教学暂停页和结算页外，大多数页面依赖 Godot 几何推断；联机按钮还会按状态显隐 | 键盘/手柄焦点可能跳到不符合阅读顺序的位置 | 为主菜单、关卡分类+节点+进入、设置页脚、联机状态按钮建立显式可回环焦点链 |
| P1 | 字体角色 | 行书用于联机房间的部分操作性小字；Noto Sans 同时承担标题与正文 | 小字号行书辨识度下降，标题层级又不够有性格 | 行书只用于 26 px 以上标题/章名；Noto Sans 用于按钮、正文、数值与状态 |
| P2 | 低分辨率 | 960×540 下设置页和主菜单按比例缩小，视觉仍完整但文字进入疲劳区 | 小窗口或低分辨率显示器体验下降 | 在“设置最小窗口尺寸”和“增加 960 紧凑布局”中选一条作为正式约束 |

| P2 | 空状态 | 战局左下单位面板在未选中时保持完整大框，只显示“未选择棋子” | 视觉重量与信息量不匹配 | 未选中时折叠为 56 px 提示条；选中后 160 ms 展开详情 |

## 按钮补间分级

### 全局基础反馈

- Hover：140 ms，`TRANS_CUBIC + EASE_OUT`，缩放 1.02–1.035，位置上移或向操作方向移动 2–6 px。
- Press：80 ms，缩放 0.955–0.97，明度降 10%–14%。
- Release：120 ms，`TRANS_BACK + EASE_OUT` 回到 1.0；避免弹性过强。
- Focus：160 ms，仅做边线/光环和 1.01–1.015 缩放，保证键盘焦点稳定。
- 每个控件保存并杀死旧 Tween，禁止同一属性堆叠竞争。
- “减少动态效果”开启后关闭缩放、位移、抖动，只保留 80–120 ms 色彩/透明度变化。

### 需要强反馈的按钮/动作

| 页面 | 控件/动作 | 建议反馈 |
|---|---|---|
| 主菜单 | 联机对战、关卡模式 | 剑身短促出鞘 6 px，金线从左向右扫过；确认后整组菜单收束并进入转场 |
| 关卡选择 | 进入关卡 | 80 ms 压下 + 180 ms 印记/边框亮起；对应路线节点同步回应 |
| 联机房间 | 确认准备、开始游戏 | 准备：红/玄席位状态板锁定；开局：260 ms 中央“对阵”牌落定后转场 |
| 正式战局 | 确认行动、跳过/结束回合 | 确认：棋盘落点脉冲 + 按钮压印；跳过：要求二次确认或短暂 hold，避免误触 |
| 设置 | 应用 | 压下后出现 220 ms 金色印记，状态文字在按钮上方淡入；显示模式变更继续保留 10 秒恢复机制 |
| 设置 | 重置进度 | 铁红边框与短促 4 px 抖动，之后打开确认框；不能使用与“应用”相同的金色奖励反馈 |
| 加载失败 | 重试 | 按下后错误标记收束为加载印章，立即进入重试态 |
| 教学 | 继续、下一章、重试 | 继续/下一章使用确认反馈；错误答案只抖动选项本身，不震动整个教学栏 |

### 不应强化的控件

- 音量滑块拖动、滚动条、普通返回、文本输入、页签切换只使用轻反馈。
- 长时间循环呼吸只用于“当前可行动点”或“等待另一位玩家”，且同屏最多一处。

## 字体与字号规范

| 角色 | 字体 | 1280×720 基准 | 用途 |
|---|---|---|---|
| Display | ramega 张青平行书 | 28–44 px | 页面标题、章节名、阵营气氛字 |
| Heading | Noto Sans SC 600 | 20–28 px | 面板标题、关卡标题、结果标题 |
| Body | Noto Sans SC 450–500 | 16 px / 24 px 行高 | 教学正文、任务描述、设置标签 |
| Secondary | Noto Sans SC 450 | 14 px / 20 px 行高 | 快捷键、提示、次级状态；不可承载核心规则 |
| Control | Noto Sans SC 550–600 | 16–20 px | 按钮、页签、选项框 |
| Numeric | Noto Sans SC 500，等宽数字 | 16–28 px | 回合、比分、百分比、房间号 |

文本颜色建议固定为四级：主文字 `#E8DEC5`、强调金 `#E8BC62`、次级文字 `#AFA58F`、禁用 `#6E6A61`。纹理背景上的正文统一增加 1–2 px 深色描边或独立半透明衬底。

## 布局建议

1. 保留 1280×720 为核心安全画布，同时增加 960 紧凑布局或明确更高的最小窗口尺寸。
2. 超宽屏只延展背景与环境装饰，不拉伸按钮、面板和棋盘比例。
3. 正式战局保持“左信息—中棋盘—右目标”的结构；优先把右栏正文变大，并让左下单位卡在空状态折叠。
4. 教学不要继续挤进正式目标面板；使用独立教学抽屉，但复用正式 UI 的材质、标题条和按钮预置。
5. 设置页使用容器管理的单列设置表与固定页脚，减少中心空白。
6. 所有按钮最小高度以 48 px 为下限；高价值主按钮使用 56–64 px。

## 推荐实施顺序

1. 建立新的字体/颜色 Theme 变体，并修复正式 HUD、教学 HUD 字号和对比度。
2. 重排教学抽屉，解决右栏遮挡与滚动问题。
3. 把主菜单、关卡、联机、教学和结算的关键按钮迁移到预置 `UiMotionButton` 变体。
4. 清理 `motion_profile = null` 的实例覆盖，新增 Confirm / Danger 反馈分组。
5. 完成显式焦点链和低分辨率/超宽屏三档测试。

## 验收标准

- 1280×720 下核心战局与教学正文不小于 15–16 px。
- 960×540 或正式声明的最小窗口尺寸下，没有文字裁切、按钮低于 44 px、面板互相遮挡。
- 21:9 下背景填满，核心功能区保持安全画布且无拉伸。
- 鼠标、键盘和手柄三种输入能在所有主要页面完成闭环导航。
- 开启“减少动态效果”后无位移、缩放、抖动和循环呼吸。
- 同一语义按钮在不同页面使用一致的 hover、press、focus 与 disabled 反馈。
