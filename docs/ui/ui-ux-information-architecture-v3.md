# 《雾疆：九路烽棋》UX、视觉清晰度与文字表达规范 v3

日期：2026-09-02  
适用范围：除开始菜单外的正式页面、对局 HUD、教程和系统模态框  
开始菜单状态：保护原版，不接入本规范的主题改造

## 结论

上一版“玄铁军帐”方向在材质选择上成立，但执行结果结构性失衡：外框、内框、卡片和按钮同时使用高复杂度金属纹样，导致装饰层级压过信息层级。v3 不增加装饰，而是把东方战争奇幻感集中在少数高识别位置，让玩家先看懂“现在是什么状态、下一步做什么”，再感知世界观。

## 红队审查

### Verdict

**Viable with major risks（具备基础，但必须重建层级）**。

页面任务结构大体正确，问题主要发生在视觉编码：所有层级争夺注意力，正文和状态反而退入背景。继续叠加纹样只会放大失败，必须先限定视觉预算并重排阅读优先级。

### 最可信的失败机制

1. **装饰竞争**
   - 原因：页面框、栏目框、卡片、字段和按钮都使用厚重包边与角饰。
   - 后果：玩家无法在一眼内判断主任务区和次要信息区。
   - 修正：每页只保留一个强识别外框；普通栏目改为安静的铁黑平面和单侧铜线。

2. **语义颜色失效**
   - 原因：标题、数字、边框、焦点和普通文案大量共用金色。
   - 后果：金色不再代表重点，确认与危险操作只能依靠按钮位置猜测。
   - 修正：暖白承担阅读，青铜只承担层级与焦点，玉绿只表示安全推进，朱砂只表示风险和错误。

3. **正文退化为背景噪声**
   - 原因：辅助文案亮度过低，复杂纹理直接位于文字后方，行距和标题权重又不稳定。
   - 后果：玩家跳过规则、状态和操作提示，教程尤其容易形成误操作。
   - 修正：正文对比度优先于材质；文本区域使用纯净内槽；正文 16 px、24 px 视觉行距，辅助文字不得低于可读灰阶。

4. **按钮层级扁平**
   - 原因：返回、页签、普通操作和主操作都像同一种金属牌。
   - 后果：页面没有明确的“下一步”，危险操作也不够隔离。
   - 修正：普通/返回按钮使用轻量铁片；每屏最多一个主按钮；确认使用玉绿，危险使用朱砂并与主操作保持空间间隔。

5. **字体风格替代信息层级**
   - 原因：装饰字体被用于章节、栏目和数字等大量位置。
   - 后果：同一页面缺少稳定阅读节奏，数字和短标签的辨识速度下降。
   - 修正：书法只用于页面题签和终局结果；Noto Sans SC Semibold 用于任务与栏目标题；Noto Sans SC Regular 用于正文；数字使用 Semibold，禁止书法化。

## 全局阅读顺序

所有页面必须按以下顺序组织注意力：

1. **当前状态**：所在页面、当前回合、连接状态、胜负结果。
2. **下一步行动**：当前唯一推荐操作，或当前需要完成的任务。
3. **决策上下文**：关卡目标、席位、行动预览、教程步骤。
4. **参考信息**：规则说明、统计、历史、提示。
5. **装饰与气氛**：只允许强化前四层，不得独立争夺注意力。

## 页面任务流

| 页面 | 玩家任务 | 首屏阅读顺序 | 唯一主操作 |
|---|---|---|---|
| 设置 | 修改选项并安全保存 | 页题 → 当前分类 → 设置项 → 保存状态 | 应用设置 |
| 关卡选择 | 找到适合的关卡并理解目标 | 分类/路线 → 关卡列表 → 目标与状态 | 进入关卡 |
| LAN 大厅 | 创建或加入并完成开局准备 | 连接状态 → 房间动作 → 席位状态 → 规则 | 创建/加入/准备/开始（随状态唯一出现） |
| 对局 HUD | 理解回合并完成一次合法行动 | 行动方与计时 → 棋盘 → 选中单位/预览 → 确认 | 确认行动 |
| 教程引导 | 完成当前一步 | 本章目标 → 当前军令 → 必做步骤 → 可选解释 | 当前步骤按钮 |
| 图鉴 | 记住一个规则结论 | 页题 → 一句话结论 → 图示 → 三步解释 → 易错点 | 下一页 |
| 终局 | 理解结果并选择后续 | 胜负 → 原因 → 核心统计 → 后续动作 | 与当前上下文匹配的默认动作 |

## 视觉预算

- 每页最多一个高复杂度九宫格外框。
- 每个模态框可以使用一个高复杂度军令框；模态内部不再嵌套同等级纹样。
- 普通 `PrimarySurface` / `SecondarySurface` 使用平面玄铁和 1 px 边线；只有任务区可使用 3 px 左侧青铜强调线。
- 每屏最多一个玉绿或亮金主按钮；普通按钮不得与主按钮同亮度。
- 大面积纹理上禁止直接放正文，必须先提供不透明度足够的文字承载面。
- 状态色必须同时配合文字，不以颜色作为唯一信息。

## 字体系统

| 角色 | 字体 | 建议尺寸 | 用途 |
|---|---|---:|---|
| `DisplayTitle` | 张庆平行书 | 42 px | 胜利、败北、章节大题；单屏最多一次 |
| `ScreenTitle` | 张庆平行书 | 32 px | 页面题签，如关卡模式、联机房间、军帐设置 |
| `SectionTitle` | Noto Sans SC Semibold | 19 px | 栏目和当前任务标题 |
| `BodyText` | Noto Sans SC Regular | 16 px | 规则、说明、操作反馈 |
| `SecondaryText` | Noto Sans SC Regular | 14 px | 帮助、补充状态、时间与来源 |
| `NumericText` | Noto Sans SC Semibold | 20 px | 回合、进度、房间号和比分 |

书法标题必须配合暗色描边或阴影，并保持短句；按钮、表单、长文和数字禁止使用书法字体。

## 色彩语义

- 暖白 `#E4DED0`：正文与普通按钮文字。
- 次级灰褐 `#ABA395`：帮助文案，最低层级但仍须清晰可读。
- 旧青铜 `#B58A45`：标题装饰、分隔、焦点与当前选中。
- 玉绿 `#3F8C68`：安全确认、准备完成、有效推进。
- 朱砂 `#A64A3A`：危险、失败、退出、重置。
- 玄铁 `#101514` / `#171D1B`：主要承载面；同屏只使用有限的明度阶梯。

## 验收标准

- 眯眼查看截图时，仍能识别页面标题、当前状态和唯一主操作三个层级。
- 1280×720 下正文不依赖放大即可阅读；960×540 下不得继续缩小正文。
- 页面内强装饰框数量减少，普通栏目与正文区域不再使用高复杂度角饰。
- 金色面积显著降低，玉绿和朱砂只用于明确语义。
- 书法字体只出现在页面题签与终局结果；数字、按钮和规则正文保持快速辨识。
- 主菜单视觉和交互资产保持原样。
