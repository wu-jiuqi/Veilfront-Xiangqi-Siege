# 《雾疆：九路烽棋》三关试玩版说明

## 试玩目标

在 50 个完整回合内消灭全部敌方棋子。超过回合限制仍有敌军存活即判定关卡失败；我方帅被消灭也会失败。

## 关卡

- 第一关：敌方 1 枚象，部署在战区最远边界 Y=16。
- 第二关：敌方 2 枚象，部署在战区最远边界 Y=16。
- 第三关：敌方 2 枚马，部署在战区最远边界 Y=16。

我方 16 枚棋子全部位于大本营 Y=1–3。试玩棋盘只开放我方大本营、我方缓冲区和战区（Y=1–16），迷雾、城墙以及棋子在缓冲区和战区中的特殊能力继续沿用现有规则核心。

## 敌方行动

敌方只读取自身玩家视角可见信息。每个敌方回合会枚举可移动落点；如果可见信息已经能证明某落点会被我方吃掉，该落点会先被排除，再从剩余安全落点中按种子随机选择。没有安全落点时才从全部合法落点中随机选择。

## 操作

- 左键：选择棋子、选择目标点。
- Esc / 选中棋子时右键：取消当前选择。
- 未选中棋子时右键：添加本地圆、叉、方形标注。
- 鼠标滚轮或棋盘滚动条：查看大本营、缓冲区和战区。
- 顶部“选择关卡”：切换三关并按当前种子重新开局。
- 顶部种子：输入整数后可复现相同的敌方随机行动序列。
