为什么这样做

九路棋盘的棋子落在交点上。左键选择，右键取消；确认前可以随时更换落点。

  2. 点击相邻的金色交点。

高价值动作获得强反馈，普通控件保持克制。顶部“减少动态效果”会关闭缩放、位移与抖动，只保留颜色变化。

按钮反馈分级

悬停、按下与焦点使用同一运动语法，语义通过颜色和结束反馈区分。
