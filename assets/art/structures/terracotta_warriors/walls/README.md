# 兵马俑管线平面城防阵线

本目录是 `TASK-ART-001` 的红方城墙三状态样片。城墙表现为贴合棋盘表面的城防阵线，不是实体碰撞墙。

| 文件 | 规则状态 | 说明 |
|---|---|---|
| `red_wall_intact.svg` | `INTACT` | 连续双层金属嵌线与九路节点，表达封锁生效。 |
| `red_wall_breached.svg` | `BREACHED` | 全线均匀断裂，不暗示单一可通行缺口。 |
| `red_wall_repairing.svg` | `REPAIRING` | 保持断裂并加入重组能量，不能误读为已经恢复。 |

## 运行时规格

- 源图与样片运行时均为 `2048×192` 透明 SVG；进入正式批量前再决定是否派生为 PNG。
- Godot 3D纹理使用 VRAM Compressed、mipmap 开启、Fix Alpha Border 开启。
- 平面宽 `10.6` 世界单位、深 `0.72`，根节点锚定权威墙线；视觉平面离棋盘 `0.018`。
- 资源没有碰撞体，不参与规则、寻路、点击或信息判断。
- 状态只接受观察者安全 `PlayerView.walls[].status`；不表现入侵数量和修复内部计时。

黑方资源在红方样片通过可读性审查后，按同一几何与状态语义制作独立阵营材质变体。
