# 《雾疆：九路烽棋》准确性优先教程示意图 v3

## 决定

本图集不追求与正式美术风格一致，唯一优先级是让玩家准确读出规则关系。18 张运行时图片全部由 `tools/art/build_tutorial_diagrams_v3.py` 确定性绘制，不使用生成模型承载棋盘坐标、数量、方向、路径或状态机事实。

精确规则仍以 `docs/prototype/rules-spec-v1.md` 的 owner-freeze revision 5 为准；Godot 文本层继续解释完整条件、步骤和例外。图中只嵌入帮助读图的短标签，不复制长篇规则正文。

## 统一视觉语法

- 赤色圆棋：赤方；蓝色圆棋：玄方。蓝色用于提高对比度，不改变规则阵营名称。
- 绿色箭头/对勾：允许、成立或完成。
- 琥珀色：条件、等待、随机或公开风险。
- 红色叉号：阵亡、阻挡、越界或已知不可行。
- 灰色：迷雾、隐藏或未完成状态。
- 棋盘线的交点才是落子点；亮色圆点表示交点集合，不表示格子中心。

## 生成与检查

```powershell
python tools/art/build_tutorial_diagrams_v3.py
python tools/art/build_tutorial_diagrams_v3.py --check
```

`manifest.json` 记录 18 张图片的尺寸、SHA-256 与规则章节。图片统一为 1200×800 RGB PNG，适配运行时 3:2 图鉴区域。
