# 《雾疆：九路烽棋》四格漫画新手教程 v1

## 定位

- 目标：用连续四格漫画替代大段规则说明，让未玩过象棋的玩家也能按页理解。
- 视觉：黑铜、旧金、朱砂红、烟灰；90°俯视或高俯角；无脸陶俑/金属军阵；画面优先、文字从简。
- 结构：每页只讲一个规则概念；数字、方向和状态变化必须直接画出。
- 当前依据：`docs/prototype/rules-spec-v1.md` 与项目现有美术资产。
- 待校准：项目与关联知识库未找到用户所指 PPT；获得源 PPT 后需逐页核对标题、术语、规则覆盖和页序，再发布 v2。

## 发布前检查

1. 用源 PPT 对照所有规则页，处理新增、废弃或不同命名。
2. 游戏内嵌时不要依赖图片文字作为唯一信息源；标题和短标签应另做本地化文本层。
3. 逐页验证数字：9×24、3×3、2 发、取 3、三子、2–5 格、1/3→3/3。
4. 逐页验证因果：隐藏单位不得预先露出；旗帜进度绑定同一棋子；完整墙与特殊资格状态一致。
5. `page_00` 的长棋盘和 `page_16` 的满营画面属于漫画化示意，精确坐标与容量以规则规格和游戏内网格为准。

## 生成说明

- 生成方式：Codex 内置图像生成模式；以项目 HUD、棋盘背景与陶俑棋子 PNG 作为视觉参考。
- 规则性返修：炮击页修正为严格九点目标区；旗帜争夺页修正为单一占领棋子；胜负页补齐红黑将帅同窗死亡；后备页强化“无空位/自动部署”的因果。
- PDF 构建：`tools/docs/build_comic_tutorial_pdf.py`。
