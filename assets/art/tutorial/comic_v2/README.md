# 《雾疆：九路烽棋》战阵图鉴插图 v2

## 本轮决定

v2 不再让生成图片承担精确规则说明。每张图只表现一个记忆焦点；标题、数字、步骤、例外和易错点全部由 Godot 的独立文本层呈现。这样可以避免图片内伪文字、错误箭头和不可靠棋盘坐标被玩家当成规则。

## 生成方式与统一提示词

- 模式：Codex 内置图像生成。
- 参考：v1 对应页用于题材参考，`page_00_board_turns.png` 用于统一 v2 的水墨、旧纸、朱砂、炭黑与旧金风格。
- 画幅：单场景、横向 3:2，适配游戏内约 540×360 的图片区。
- 固定约束：90°俯视或接近俯视；主体轮廓清楚；留出安全边距；不生成文字、字母、数字、汉字、标题、UI 面板、分镜、箭头、虚线、带字旗帜或带字印章。
- 准确性原则：凡涉及数量，提示词写明 `EXACTLY` 并指定位置；凡涉及隐藏信息，只画玩家应该记住的公开关系，不画精确规则结论。

统一提示词骨架：

> 为 90°俯视东方战争奇幻策略游戏生成一张单场景 3:2 教程记忆图。沿用旧纸、水墨、朱砂红、炭黑、旧金风格。只表现指定的一个视觉关系，并严格满足指定数量。图片只作助记，精确规则由 Godot 文本层显示。禁止任何文字、数字、字形、标题、UI 面板、分镜、箭头、虚线路径和带字装饰。

## 使用约束

- 图片不能单独作为规则事实源；运行时事实源为 `scripts/game/tutorial/tutorial_codex.gd`，并继续追溯 `docs/prototype/rules-spec-v1.md`。
- 后续修改规则时先改权威规则与 Godot 文本，再判断图片记忆焦点是否仍成立。
- 禁止在图片上重新叠加不可本地化的正文。页码、标题、步骤和状态词一律保留为 Control 节点文本。
