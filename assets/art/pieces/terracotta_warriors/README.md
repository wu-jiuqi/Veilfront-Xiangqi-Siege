# 兵马俑静态棋子运行时纹理

本目录存放可由 Godot 直接导入的“兵马俑”管线静态棋子纹理。

- 红方：银白钨钢。
- 黑方：深墨绿青铜。
- 人形棋子：`512×768`，脚底锚点 `(0.50, 0.94)`。
- 骑兵、战车、抛石机：`768×768`，接地点锚点 `(0.50, 0.92)`。
- 透明处理：纯紫幕色键去背后，以预乘 Alpha 等比缩小。
- 生成与验证证据：`evidence/gate2/art-samples/`。
- 机械验证：`evidence/gate2/art-samples/TW-PIECE-01-14-runtime-validation-v2.json`，14/14 通过。

文件名不包含版本号；版本历史由 Git 管理。当前纹理是静态美术测试候选，正式秦小篆矢量字和 Godot 盘内可读性仍需单独验收。
