# 首页视觉概念图

本目录存放尚未拆分为 Godot 运行时资源的首页视觉概念图，只用于构图、风格和信息层级评审。

## 当前方案

- `main_menu_concept_v4_colossal_gate_project_soldiers.png`：`1672×941` RGB 当前概念图。采用深蓝灰与墨绿青铜色调；青铜双扇门放大到超出画面边界；左右分别使用项目现有银白兵与墨绿青铜兵的造型和材质；移除顶部游戏 Logo，只保留`帅／将`门章、三个菜单入口和版本号。
- `main_menu_concept_v3_bronze_gate.png`：`1672×941` RGB 上一版青铜门概念图。确定了双扇门、左右甲士和雾气构图，已被 V4 的巨门裁切、项目士兵材质和深色调修订取代。
- `main_menu_concept_v2_ink_xiangqi.png`：`1672×941` RGB 上一版概念图。以水墨棋盘和圆形棋子作为主体，已被 V3 青铜门构图取代，保留用于方案演进对照。

## 使用约束

- 图中文字、棋子字形、棋盘线条和印章均为生成式概念内容，不得直接拆出作为可发行生产母版。
- 正式棋盘仍需使用项目精确的 `9×24` 交点矢量资源，不得照抄概念图中的格线和残局位置。
- Godot 实现继续使用预置 `Control / Container / Theme`；概念图只提供视觉目标，不承担交互、焦点或规则状态。
