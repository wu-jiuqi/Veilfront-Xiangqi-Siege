# 联机房间 UI 资产

- `lan_lobby_full_plate_v2.png`：项目所有者批准的高保真视觉母版，只作为切片源和视觉对照，不再被运行时场景引用。
- `lan_lobby_board_backdrop_v1.png`：运行时独立战场背景。
- `slices_v3/`：由母版确定性生成的功能切片、按钮状态贴图、动态文字背板及切片清单。
- `slices_v3/slice_manifest.json`：记录每块 PNG 在母版中的原始坐标，便于审计和重新生成。

## V3 运行时策略

- 场景由顶部栏、房间信息、阵营展示、规则、状态栏和操作栏等独立 `TextureRect` 拼装，不存在整屏母版节点。
- 返回、复制、离开、加入、创建使用有正常、悬停、按下和禁用贴图的预置 `TextureButton`。
- 房间代号、局域网地址、连接状态和双方席位由真实 Godot 文本控件渲染；母版示例文字由细颗粒 PNG 背板覆盖。
- 默认地址自动选择本机非回环 IPv4，并追加端口；房间代号按端口稳定生成。
- 当前高保真基准仍为 1280×720、16:9。

## 重新生成

在项目根目录运行：

```powershell
python scripts/dev/ui/slice_lan_lobby_art.py
```

脚本只读取批准母版并写入 `slices_v3/`，不调用生成式模型，也不会修改源图。
